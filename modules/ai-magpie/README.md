# 共享 AI 适配器

截图 OCR、翻译、划词助手、快捷助手和学习共用 Magpie。供应商、账号登录和模型由 WinOne 的 AI 服务统一管理；各功能只选择已启用的供应商与模型，不另存凭据。

main 的 AI 服务只保留常用、自定义供应商、账号供应商、本地网关，使用偏好已并入常用。完整旧版保存在 `codex/archive-full-20261112`，本次对齐见 [AI 服务完整更新](../../docs/performance-ai-20261128.md)。

## 来源与构建

Magpie 固定为 `0d310af00f2934b4331609251340e7336a1f9d0c`，MIT。账号适配器固定为 `46ba1e4eb4b26c4b4993709e78e7841562fa5c41`，保留 49 个经过资源清单验证的账号适配器，旧 Antigravity 资源仅服务已有连接。Bun 固定为 Windows x64 baseline 1.4.2。完整来源、文件摘要及许可证见 `third_party/ocr-ai-notices.json`、`third_party/ai-plugins.json` 和 `third_party/import-notices.json`。

通过 `build/build-ai.ps1` 构建，传入 Magpie 源码、账号适配器源码、Bun 和 Go 路径。脚本从固定提交建立独立源码副本，核对来源和许可，编译 `WinOne.AI.exe`；不链接上游完整桌面界面。最低 Go 版本为 1.26.8，本仓库复用已登记的 Go 1.27.3。`upstream.go.mod` 和 `upstream.go.sum` 保留固定上游的依赖快照。

## 账号与模型

每个供应商使用独立账号目录。固定适配器通过内存注册，旧的 `plugins.json` 不能加载额外插件。保留登录方式选择、前置问题、设备码、API 密钥、浏览器回调、授权码、账号选择、模型发现与生成；缺少官方客户端时明确报错，不自动安装。

普通账号列表每次读取当前私有认证文件，并复用已核实的名称与登录方式。`winone-account-provider.json` 只保存公开发现资料及依赖指纹，不保存凭据或账号快照。首次使用创建私有目录；安装位置、账号类型或适配器版本变化后重新验证和发现。后台不运行独立插件管理、外部客户端会话或全局用量服务。

模型报告与用户覆盖分开保存。上下文、输出上限、思考、图像和价格默认由 Magpie 的供应商目录决定；仅主动修改的字段进入上游设置。保留名称、别名、协议、系统提示词、媒体类型、Token 压缩阈值及旧比例兼容。完整原始目录继续使用上游缓存，原网关负责模态、能力、请求参数和公开模型列表。

请求头、代理、证书、全部启用密钥、权重、账号额度及供应商预算贯通模型发现和实际调用。密钥选择、冷却、并发及 RPM 使用原网关与 `routes.Builtin`；中转充值倍率及 sub2api 密钥分组倍率读取沿用原 `KeepKeyRatesRead` 与价格计算，用户的单密钥覆盖优先。Responses 原生供应商支持 `/v1/responses/compact`，由原网关检查协议、密钥只读/并发和模型权限。密钥选择及路由使用原网关与 `routes.Builtin`，Host 不再另写策略。只有明确启用自动发现的供应商会定时刷新；保存配置会取消并等待旧刷新结束。连接说明直接执行上游完整 `pasteread.js` 及地址辅助函数；cURL、环境变量和 JSON 均只作为数据，不执行粘贴的命令或自动保存密钥。

## 独立本地网关

Host 负责公开监听地址、认证、模型选择和进程生命周期。网关只接受 `internal/ai/gateway_paths.go` 中的协议路径；密钥、预算、OIDC、调用录制和最近调用使用独立私有管理接口。没有路由组、通用插件管理、脱敏、全局用量、请求归档或外部客户端服务入口。

网关密钥预算和供应商预算仍使用必要的内部调用元数据；这不是独立统计服务。网关调用正文只在用户明确开启录制后保存。每个设置页面持有自己的网关租约；旧页面迟到的关闭不能终止新页面或已启用的公开网关。

普通结果和本地网关共用按需启动的上游运行实例。设置页和结果调用方各持有独立租约；调用方进程结束，且没有网关或设置页所有者后释放。自定义供应商直接接入原 Provider，账号操作继续使用独立档案。独立单次调用仍可使用受 Host 管理的短命工作进程；不再由 Host 重试一个已由上游处理的请求。

## 验证入口

- `build/build-ai.ps1 -Test`：真实适配器、账号快照、登录隔离、协议转换和错误传播。
- 设置 `WINONE_AI_TEST_EXE` 与 `WINONE_GATEWAY_TEST_EXE` 后运行 Host 和 `internal/ai` 回归：使用隔离账号目录与本地 HTTP 夹具验证请求、密钥、预算、模型策略、流式输出、录制及生命周期。
- `build/test-ai-native-windows.ps1`：在私有桌面运行原生设置窗口与真实网关，核对保存、明细和页面关闭。

测试数据、日志、候选包与准备源码位于本次 `_temp/<任务>/`，不得进入分发目录。默认测试不读取真实账号或修改真实安装。
