2026-10-08。安装、卸载、版本更新与跨配置版本迁移已贯通，当前 Host 空闲内存已获用户接受；共享依赖和整应用升级预检仍待完成，尚不作为完整扩展支持交付。最新行为与证据见 [模块版本更新与恢复](模块版本更新与恢复.md) 和 [模块配置迁移](模块配置迁移.md)。

## 当前行为

工具管理的“安装模块”打开 Windows 文件选择器。选择本地 `.winone-module` 或 ZIP 后，Host 只读验证发布者签名、完整文件清单、摘要、配置定义与兼容性，再显示来源、名称和版本。取消不登记或执行模块。失败可直接重新检查原文件。

确认只提交当前窗口拥有的一次性预览标识。Host 重新核对源文件、信任和配置/模块/包登记修订，再暂存、登记、提交配置和绑定运行时。安装后保持关闭；启用、修改设置、重启继续复用统一 Host 和配置中心。

卸载当前要求先关闭模块。确认后验证资源恢复和实际退出，保留配置，移除登记，再将验证过的程序目录送入回收站。回收失败会返回“已卸载、文件待清理”的提示。相同配置版本的重装恢复保留内容，并保持关闭。

安装在包登记之后遇到配置或模块状态写入失败时，显示可恢复的不可用模块；不显示成功，不开放 Worker 命令。释放文件占用后，恢复入口补齐登记、配置和运行时绑定。预览及确认状态不存储账号凭据。

## 资源结果与剩余范围

首次预览和安装后，模块关闭时 Host 私有工作集峰值 **42.13 MiB**，私有提交峰值 55.25 MiB。用户于 2026-10-08 明确接受约 43 MiB，并要求优先完成正式版；该记录已通过调整后的 Host 空闲检查，不再因原 40 MiB 数值阻断交付。测试 Worker 启动后完整进程组私有工作集峰值 81.78 MiB、私有提交峰值 109.67 MiB。该场景包含首次安装，不能与历史“启动发现既有包”的数值直接相减作为增量。采样和二进制摘要均已保留。

Go 1.27.1 的标准库仍有静态熵缓冲；上游问题 #81956 仍开放。没有将实验标准库覆盖放入产品，也没有降低预算。归因依据见 [Go 标准库内存记录](Go标准库内存诊断.md)。
