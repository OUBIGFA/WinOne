# 快捷助手

快捷助手以 AI 对话为主，位于划词助手下方。默认按 Ctrl+Shift+Q 呼出；再次呼出激活同一窗口，保留本窗口消息和输入草稿。供应商与模型统一来自 AI 服务。

## 使用与界面

- Enter 发送消息，Shift+Enter 换行；支持连续对话、流式输出、停止、重试、临时切换模型和新对话。
- 输入区上方提供翻译、解释、总结、润色、代码及自定义功能。功能组在所在区域内水平、垂直居中。数量较多时进入“更多功能”。
- 快捷助手工具栏不显示复制功能；划词工具栏及每条回复的复制操作保留。
- 划词工具栏采用「Logo｜功能图标｜快捷助手」布局，两条细竖线分隔，右侧快捷助手入口与左侧 Logo 使用相同占位。点击右侧入口会唤醒快捷助手，把选中文字填入输入框，不自动发送；已有草稿时另起一段加入。此过程不改写系统剪贴板。
- 点击功能后保留原输入。继续点击另一功能仍处理原输入，不把前一条结果当成新输入；新结果加入当前对话。
- 两个助手共用默认动作定义、请求构造、图标与动作校验。快捷助手独立保存顺序、显示状态、自定义指令和动作模型选择。
- 对话图标统一采用本地 Lucide MessageCircle，覆盖导航、模块列表、打开入口、新对话和自定义动作图标。
- 润色图标统一采用 Lucide PenLine（笔与横线），覆盖两个助手的工具栏、设置预览及图标选项。
- 快捷助手默认固定窗口，避免切换应用时中断对话。置顶图标在未置顶时使用更淡的颜色，置顶后恢复正常颜色，并将同一图标顺时针旋转 45°，与 OCR 和翻译窗口一致；系统高对比度模式保留系统配色。取消固定后沿用结果窗的失焦关闭行为。关闭窗口会取消请求；本次会话不写入磁盘历史。

## 快捷键与配置

| 功能 | 新默认快捷键 |
| --- | --- |
| 快捷助手 | Ctrl+Shift+Q |
| 截图翻译 | Alt+Shift+A |
| 截图识别并复制 | Shift+C |

已有显式保存的快捷键及空值保留。旧配置占用 Ctrl+Shift+Q 时，不覆盖原动作；快捷助手的快捷键可在其设置页重新录入。缺省快捷键先按完整配置计算，再按模块启用状态注册。

模块配置及模块状态按基础模块版本 3 迁移。已有模块开关、待恢复状态与之前的划词迁移备份保留；版本 2 升级使用独立的 .before-quick-assistant.bak 备份。配置导入、导出和修订冲突校验覆盖快捷助手。

## 实现与验证入口

- 默认动作与请求：internal/resultwindow；快捷助手偏好：internal/quickassistant。
- Host 接入：apps/host/quick_assistant_windows.go、quick_assistant_configuration_windows.go、result_quick_assistant_windows.go。
- 窗口直接复用 apps/result-ui；不新增独立 UI 运行时或常驻助手进程。禁用模块会释放快捷键，并关闭仅属于快捷助手的结果窗口。
- 设置直接复用划词助手的动作编辑器，通过 QuickAssistant 桥接方法保存到独立模块配置。
- 原生组件检查：apps/result-ui/quick_assistant_layout_test.go；实窗设置检查：apps/desktop/frontend/tests/rust-quick-assistant-check.mjs。
- 划词到快捷助手的实窗检查：build/test-selection-quick-handoff.ps1。验证真实选中、点击入口、首次填入、保留已有草稿、窗口复用及停用回收。
- 安装启动检查使用共享结果宿主的只读 --check-startup 握手，不把它当作独立 Worker 启动。

划词交接实窗检查使用候选包中的 Host、划词模块和共享结果窗口。显式运行以下命令，会短暂操作测试窗口的鼠标与键盘；配置、截图和报告写入指定的新目录。

```powershell
./build/test-selection-quick-handoff.ps1 -BundleDirectory _temp/build/current -OutputDirectory _temp/selection-handoff-check
```

需要指定 .NET 工具位置时传入 `-DotnetExe`。输出目录必须位于仓库 `_temp/` 下且尚不存在。成功后输出 `run/quick-handoff.json`，记录首次输入、第二次追加输入、草稿保留、剪贴板不变、窗口进程复用及模块停用回收结果。此检查不发送 AI 请求。
