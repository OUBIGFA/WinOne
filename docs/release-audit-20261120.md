## 验证结果

完整统一构建在 `66cdd47` 通过。其后按真实依赖重编设置窗口、Host 和安装辅助程序，复验受影响测试及整个包。来源逐项记录，未将不同构建提交混写成一次全量重建。

| 最终检查场景 | 本机结果 | 样本与范围 |
| --- | --- | --- |
| 设置窗口首次新配置启动 | 243.28 ms | 首次新进程，不等于清空系统文件缓存的冷启动 |
| 同配置重开 | P95 106.74 ms | 20 次新进程，300 ms 目标通过；21 次观察到的界面进程均退出 |
| 设置窗口打开 | 私有工作集峰值 41.47 MiB | Host + UI，15 个完整样本，模块关闭 |
| 设置窗口关闭 | 私有工作集峰值 9.36 MiB | 仅 Host，15 个完整样本；UI 正常退出约 183 ms |
| 全部模块关闭空闲 | 私有工作集峰值 9.16 MiB | 15 个完整样本，14 个 CPU 区间未计得增量 |
| 基础模块全部启用空闲 | 私有工作集峰值 136.01 MiB | 完整产品进程组，15 个完整样本，14 个 CPU 区间未计得增量 |

硬件为 i7-12700K、约 64 GiB、Windows 11 build 26320。CPU 为整机容量比例；0% 只表示对应采样区间未计得增量。原始报告记录程序摘要、进程身份和采样范围。

七模块联动最终通过：编辑中关闭截图被拒绝且不进入恢复状态；主动取消后，各模块释放约 17–294 ms；托管程序保留，置顶恢复，Host 正常退出。30 个叠加负载样本的进程组私有工作集峰值 155.25 MiB，平均 CPU 约 0.155%；禁用后十个完整样本只保留 Host，峰值 11.52 MiB，CPU 未计得增量。私有桌面不验证 DWM 可见边框。

窗口关闭覆盖默认设置、两种旧 keepUIRunning 值、托盘退出、未保存草稿、运行中任务和慢释放。另验证窗口转交及 GPU 接管前能够点击和输入。没有修改真实安装或用户配置。

前一候选安装包完成九次隔离操作：两处失败回退、首装、覆盖、残缺自包含修复、卸载中断及恢复；5,910 文件哈希、登记、快捷方式、导出卸载器一致性、配置和额外文件保留均通过。最终载荷补编了实际链接共享生命周期代码的设置窗口，最终包的首装、覆盖、残缺修复与卸载四次操作均通过，耗时分别为 12.72、28.72、28.57、3.40 秒；这些是本机样本，不作为安装性能承诺。完整源码及清单检查保留，未重新准备未变化的外部依赖。

此外修复 Rust 依赖声明校验把 PowerShell 5/7 的 JSON 格式与标点排序差异误判为依赖变化的问题；两边先解析并统一排序，再逐字段比较，许可证原文和摘要检查不变。四类 Rust 清单在 PowerShell 7 通过，diagram 清单在 Windows PowerShell 5 交叉复验通过。
