# Chat 项目迁移与完整任务导出

本次增加任务跨项目迁移和 Cindy `.cshare` 完整导出。迁移只改变项目归属及后续工具的工作目录；历史文件、保存位置、附件和草稿保留。导出使用原生另存为对话框，文件内容由 Host 的独立 Pi 导出进程采集和写入，前端只接收结果。

## 来源与实现

直接复用 Cindy 固定提交 `a152497ac24d155dd46142b73dda4fa10ad08ad0` 的 [xdtshareFormat.pure.ts](https://github.com/makecindy/cindy/blob/a152497ac24d155dd46142b73dda4fa10ad08ad0/apps/desktop/src/main/session-share/xdtshareFormat.pure.ts) 和 [xdtshareCrypto.ts](https://github.com/makecindy/cindy/blob/a152497ac24d155dd46142b73dda4fa10ad08ad0/apps/desktop/src/main/session-share/xdtshareCrypto.ts)。两个文件原样保存在 `modules/chat-pi/cindy/`，构建按 `third_party/cindy/session-share-source.json` 校验 SHA-256。Apache-2.0 许可证及 NOTICE 随 Chat 运行时分发。

采集流程核对了完整的 [sessionShareExport.ts](https://github.com/makecindy/cindy/blob/a152497ac24d155dd46142b73dda4fa10ad08ad0/apps/desktop/src/main/session-share/sessionShareExport.ts)。WinOne 使用 Pi 原生 JSONL 与自身索引代替 Cindy 的 Electron/数据库读取；继续采用同一二进制封装、ZIP 路径、摘要、便携转录标识和加密方式。JSZip 3.10.1 及其依赖共 13 项声明保存在 `third_party/chat-share-notices.json`，原文许可证在 `third_party/licenses/npm-chat-share-*`；构建校验已安装版本及许可证摘要，并复制到 `shared/chat/licenses/`。

## 接口与行为

- `chat.conversation.move({id, projectId})` 返回更新后的 `Conversation`。目标项目为空时取消项目归属，保留现有工作目录。目标项目不存在时不修改索引。
- 迁移复用会话操作锁。运行中的任务明确拒绝迁移；空闲 Worker 先释放，再提交索引。重新打开会话时，Pi 工具及资源加载器使用目标项目目录。
- 前端调用 `exportChat(id, {password?, excludeMedia?})`，对应 `Chat('export', ...)`。Rust/Wails 截获调用并打开 `.cshare` 保存对话框。前端不能指定目标路径。
- Host `chat.export` 校验真实桌面进程身份和 `.cshare` 目标位置。独立导出进程不初始化模型、不持有模型凭据、不结束当前对话；同一 Host 同时最多处理一项导出。关闭 Host 时回收导出进程。
- ZIP 包含 `session.json`、完整 `messages.jsonl`、原始 `transcripts/pi/*.jsonl`、`media-map.json`、引用的受管附件及内嵌图片、`winone/conversation.json` 和 `winone/draft.json`。不使用前端当前页或显示截断内容作为来源。
- 原生 Pi JSONL 保持逐字节一致。消息投影保留工具输入、工具输出、思考、模型及时间元数据。便携 Pi ID 来自实际转录内容摘要，不使用本机绝对转录路径作为 ID。
- 每个 ZIP 内容条目记录字节数与 SHA-256。明文与加密文件都保留 `XDTSHARE` 魔数；密码方案沿用原版 scrypt、AES-256-GCM、头部 AAD、NFC 密码归一化及随机 salt/IV。
- 默认未压缩上限为 256 MiB。先做体积检查；超限返回 `oversize`，不覆盖已有目标。只有显式 `excludeMedia` 重试才排除媒体，原始历史和消息仍完整保留。
- `full` 表示所需转录及媒体完整；缺失或主动排除媒体为 `partial`；没有可用原生转录为 `db-only`。另返缺失转录列表、媒体缺失/排除数量及字节统计。损坏或未完成的 JSONL 明确失败，不采用 Pi 解析器的静默跳行结果。
- 写入采用同目录随机独占临时文件、同步及原子替换。取消采集或读取损坏历史时保留已有导出文件。
