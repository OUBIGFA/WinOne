# 模块版本更新与恢复

2026-10-08。本地包更新已接通真实 Host 与共享设置界面。跨配置版本迁移已继续接通，详见 [模块配置迁移](模块配置迁移.md)；共享依赖和整应用升级预检仍需继续。下文保留首次同 schema 更新的验证边界。

## 更新规则

继续从“安装模块”选择本地包。已安装同一模块时，预览显示“当前版本 → 目标版本”，确认按钮改为“确认更新”。相同或更旧版本、命名空间冲突、损坏签名、配置版本不同或新版不接受当前配置时拒绝更新；不会用默认值覆盖原设置。

预览与确认绑定调用窗口、源包摘要、信任及配置/模块/包登记修订。确认时重新验证源包；过期、取消、其他窗口提交或源文件/配置改变均拒绝，且不先停旧模块。

更新使用既有包变更记录。先记录旧包和启用意图，再关闭并移除旧运行入口、切换签名包绑定、投影原配置、检查新版并确认其退出，恢复启用意图后提交。普通工作请求在该过程被统一配置队列和包状态阻止；新版通过检查前不开放入口。

新版无效且根本没有创建进程时，可以确认它没有留下进程资源，随后验证并恢复旧版本。新版启动后异常退出或拒绝资源恢复时，不把“进程已不见”当作恢复证明，保留隔离状态和恢复入口。旧版拒绝关闭也保留可重试的运行对象。资源释放后，恢复入口重新验证、确认退出并恢复旧包、配置及启用状态。

## 旧文件清理

已成功提交的更新不会因旧文件暂时被占用而回退。待回收文件保留在持久清理记录中，工具管理显示“重试清理”；释放占用后再次验证签名、文件和引用，再送入回收站。该入口同时处理更新、回退和卸载产生的退役包，不永久删除文件，也不后台轮询。

这里只清理已登记事务的退役包。尚未形成登记事务的暂存失败目录仍保留，完整暂存清理和提示属于后续项。
