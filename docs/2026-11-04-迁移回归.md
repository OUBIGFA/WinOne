## 云端网络结论

GoFile 规则模式下复现 TLS EOF。用户确认 Karing 开全局后可上传，定位为代理分流/DNS 链路，不是 TUN 本身不兼容。曾试验加密 DNS，成功一次后仍复现；该绕行方案已移除。

GoFile、croc 云端分享共用 Go 标准 HTTP 传输，优先显式 SOCKS5→显式 HTTP→环境代理→已启用的 Windows 系统代理。保留证书校验、NO_PROXY 与禁止重定向，不自行重放 POST。云端网络设置补充规则提示：`gofile.io` 及子域名走代理，TUN 可保持开启。没有修改 Karing、系统代理或系统 DNS。

croc 实际公网上传与撤销通过。GoFile 全局模式成功来自用户实测；本轮末次自动探针仍返回 EOF，不能把规则模式描述成客户端已修复。`network_test.go` 检查代理优先级、NO_PROXY、实际代理请求、无效证书拒绝和失败 POST 不重放。
