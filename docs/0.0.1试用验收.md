# 0.0.1 试用验收

更新：2026-10-03。三个模块的主要任务、截图输出及中英文布局检查已完成。**0.0.1 为本机试用版本，后续兼容性和性能范围继续按下表推进。** 交付包须通过最终构建、文件清单和哈希校验。

交付本机免安装版。日常试用版固定在 `dist/trial-0.0.1/`，测试包固定在 `dist/test/`；后续迭代只更新测试包，用户明确要求发布时才覆盖试用版。试用版交付后继续按开发文档优化。

`tests/integration/always_on_top_windows_test.go` 保留边框开启的完整测试；新增无边框模式测试只证明置顶状态和恢复，不能替代边框验收。程序管理本轮运行 `worker`、`preferences`、`internal/config`、`internal/tray`、`internal/traybox`，其中系统自启和真实桌面拖动仍按显式开关单独执行。

新原生滚动停止面板和原生重截存储属于后续接入工作，尚未进入正式入口。不能把迁移待办直接等同于现有功能缺失，也不能把新路径的局部测试当作旧路径已经验收。

本轮已获用户允许短时使用当前桌面，仅操作 WinOne 与专用测试窗口。汇总、原始日志和输出图片位于 `dist/test-verification/functional-live-1003/`；快速输入及句柄重建回归、最终构建日志位于 `dist/test-verification/pointer-1003/`。程序管理的首轮测试因运行目录错误找不到测试清单而失败，修正验证入口后通过；没有修改产品实现来绕过这项失败。
