## React / WebView2 专项核验

核验方式：GitHub 固定版本源码、发布元数据和 Microsoft 官方文档。以下结论已用于调整主方案。

| 来源 | 版本/提交 | 已检查内容 | 方案落点 |
| --- | --- | --- | --- |
| [Wails](https://github.com/wailsapp/wails/tree/v2.14.0/v2) | v2.14.0 稳定版 | README、Windows frontend.go、options.go、windows.go | Wails 只做设置宿主；Go Host 独立常驻 |
| [Wails Releases](https://github.com/wailsapp/wails/releases) | 最新列表 v3.0.0-beta.26，prerelease=true | stable/latest 返回 v2.14.0 | 首版不依赖 v3 beta |
| [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/tree/0c7e0c853545a7b7cb8664e75f017a68f6d46396) | 0c7e0c853545a7b7cb8664e75f017a68f6d46396 | package.json、tauri.conf.json、core/manager/lifecycle.rs | React 与核心分离，启停和状态有明确归属 |
| [Seelen UI](https://github.com/eythaann/Seelen-UI/tree/cb62a1b9079819af14d94d6a62c3d95394a1eee5) | cb62a1b9079819af14d94d6a62c3d95394a1eee5 | package.json、src/tauri.conf.json | 网页与 Windows 原生能力分层；仅参考，不引入其代码 |

Wails Windows 实现使用 go-webview2，内置资源起始 URL 为 `http://wails.localhost/`，具有来源校验器。配置提供 Bind、SingleInstanceLock、OnBeforeClose、WebviewUserDataPath、WebviewBrowserPath。关闭路径在 HideWindowOnClose=true 时隐藏，否则进入 Quit；存在 ProcessFailedCallback。由此确定设置独立进程、关闭退出、独立数据目录与故障重开策略。实际释放时机和恢复效果仍需 V2/V3 实测。

Clash Verge Rev 的 package.json 包含 React、Vite、Tauri；tauri.conf.json 配置 verge-mihomo sidecar；lifecycle.rs 区分服务与 sidecar 启停。这支持独立核心的产品边界，不证明其具体实现可直接用于 Go。

Seelen UI 当前 package.json 包含 Preact、Svelte 和 Tauri；不能按历史技术栈把它标成纯 React 项目。许可证为 AGPL-3.0，本轮只参考结构。

Microsoft 官方文档均已成功读取：

- [进程模型](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/process-model)：一个浏览器进程、一个或多个渲染器及其他辅助进程；测量完整进程组。
- [Evergreen 与 Fixed Version](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/evergreen-vs-fixed-version)：确定默认 Evergreen、离线发行另评估 Fixed Version。
- [运行时分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)：加入运行时缺失、安装和更新验收。
- [安全实践](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security)：加入来源校验、限制导航和最小原生接口。
