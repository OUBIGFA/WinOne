# 贴图内原文与译文切换

设置入口为“截图 → 截图后 → 贴图 → 贴图内翻译”。新增或升级的配置默认关闭。保存开关只更新贴图上的操作，创建贴图或按 Tab 均不会首次发起翻译。用户点击“翻译”之后，WinOne 用本地 OCR 获取文字位置，将待译段落交给已配置的翻译服务。

| Tools3000 能力 | WinOne 接入与核对 |
| --- | --- |
| 全图翻译、选中文字翻译、强制重译 | 五个贴图入口共用 ShareX 窗口。点击翻译全图，Shift 拖动后点击翻译局部，右键菜单可重新翻译全图。 |
| 字符定位、跨栏阅读顺序和表格 | WinOne 的 PP-OCRv6 返回文字框和字符框。Tools3000 的 XY-Cut 阅读顺序、对齐行与原子块拆分为段落引擎提供布局信息。 |
| 代码、文件名、网址和二维码保护 | 复用 Tools3000 的待译文本过滤及二维码、条形码检查。额外文字框作为排版时的避让区域。 |
| 按原图风格排版与背景修复 | 复用原位引擎、字形风格采样、OpenCV Telea 修复、DirectWrite 字号适配与避障。文字和图像始终从原图读取。 |
| 原图、译图对照及复制 | 翻译后点击底部按钮或按 Tab 切换。复制图片跟随当前显示；支持复制全部译文、另存原图及另存译图。 |
| 中断和错误 | 关闭贴图或禁用选项会取消请求；在途结果不能覆盖后来的状态。翻译失败时保持原图及已有译图。 |
| 翻译服务 | 沿用 WinOne 的供应商、目标语言和账号设置。整页统一判断翻译方向，只将过滤后的段落提交给当前翻译服务。 |

上游锁定 [Tools3000 v1.4.1](https://github.com/yuan278501381/Tools3000/tree/481c20f3444cb7cbcf1aa346896044f04602a376)。该功能于日本时间 2026-11-23 首次提交。源代码与直接依赖记录见[引入清单](../third_party/import-notices.json)和[第三方声明](../THIRD-PARTY-NOTICES.md)。

私有桌面检查可用 `build/test-capture-native.ps1 -Suites pin-translation` 复现。它使用生成图片、随包的 OCR 模型与原位引擎，将远端服务替换成本机管道夹具，检查关闭状态、显式提交、局部选字、网址保留、像素变化、切换次数和设置即时生效。该检查不访问在线翻译供应商。
