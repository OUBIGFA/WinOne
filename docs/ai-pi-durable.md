# AI 插件与 Pi Durable 能力对照

核对日期：2026-10-17。本文记录能力范围，不是完成声明。每行只有取得实际执行证据后才能标记通过。

## 固定来源

- Magpie `7660399a121af67db4efd56ecb6bd4fb04dc53f1`，MIT；账号/工具/中间件/页面插件：magpie-community/plugins `3e966bb4b5f21b9b3d1cbe6c4d15cca8fbf32fe9`，各包按其许可证。
- Pi、官方 Pi Durable `1.3.0`，MIT；不是把原 Worker 重命名为 Durable。
- pi-agent-desktop `e5a5596522fd2e52fd3b2c8997920ac6803b3086`，MIT。
- oh-my-pi `afdc8bd10e69974bfcd7565a2c6f70d1b488919c`，MIT（附带依赖另按其许可证）。

Magpie 的原生功能插件（`pluginrt`）与账号等 JavaScript 插件（`plugin`）是两套上游接口。WinOne 的“内置”指随包、锁定和校验，不把 JS 插件伪称为不需要 Bun 的原生代码。账号仍在 WinOne 私有目录，不接管其他客户端配置。用户明确不要求兼容原非插件登录；保留原数据不等于继续走旧登录分支。
