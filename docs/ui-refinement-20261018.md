## 收尾中修复的实际问题

- Windows 对带扩展名设备名称的判断存在差异；补充保留名称 stem 校验，覆盖 `aux.log`、`COM9.data` 等失败输入及 `.config`、`com10.log` 等正常输入。已有同一文件的另一个硬链接名明确拒绝，避免系统成功空操作造成误报。
- Rust 桥接补齐 `rename` 白名单及关闭保护，重命名现在可从正式桌面到达 Host。
- 原生菜单缓冲绘图时 `WindowFromDC` 可能为空；仅枚举当前线程的原生菜单窗口并设置 DWM 圆角。共享回调不会随每次弹出累积。
- AI 标题栏取消上游固定高度，防止窄窗标题重叠；移除插件头部遗留的毛玻璃伪元素，修复正文遮挡与横向滚动；修复搜索框双边框。
- 实窗驱动原先只断开 CDP，没有关闭测试窗口，外层退出检查失败。补上正常窗口关闭命令后，`native-delivery.log` 确认进程正常退出；没有为此改动产品退出逻辑。
