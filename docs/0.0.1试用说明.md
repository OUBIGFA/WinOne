# WinOne 0.0.1 本机试用

解压后运行 `WinOne.exe`。需要 **Windows 11 x64** 和 **Microsoft Edge WebView2 Runtime**。

## 常用操作

- 默认 **Shift+A** 开始截图；拖动框选，调整选区后标注或输入文字。双击复制，右键或 Esc 取消；保存和另存为使用工具栏按钮。
- 默认 **Alt+Q** 切换当前窗口置顶；在“置顶功能”中设置边框和排除程序。
- 在“程序管理”中添加程序，设置启动方式、时间和托盘收纳；保存后可立即启动。
- 关闭设置窗口后，WinOne 继续在托盘运行；从托盘选择“退出 WinOne”结束。

## 试用版与测试包

日常试用版固定在 `dist/trial-0.0.1/`。后续优化只更新 `dist/test/`，你明确要求发布新试用版时才覆盖日常试用目录。

两者共用 `%LOCALAPPDATA%\WinOne` 配置，切换前先退出正在运行的 WinOne。自动化验证使用独立配置，不导入你的程序或修改真实自启项。

## 当前验证范围

已验证截图框选、调整、标注、保存及取消；剪贴板和另存为输出逐像素一致。滚动拼接、停止及重截，置顶边框跟随与退出恢复，程序管理菜单和隔离自启任务均已有真实 Windows 验证。

中英文、深浅主题及窄窗口布局已检查。多显示器、HDR、更多第三方程序和长时间使用仍继续验证；本机试用包未提供在线更新。
