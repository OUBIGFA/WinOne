# Rust 重构审查与续做

范围：Rust 桌面、Host 配置接口及相关验证脚本。工作区包含多轮未提交改动，本次优先检查配置写入、草稿保护、快捷键与资源释放；未逐行审查截图引擎及旧网页界面的全部改动。

## 已确认问题

1. **候选源码无法编译（已修复）**：`native.rs` 未处理 `worker.rs` 最后新增的六类模块和配置请求，构建报 E0004。已补齐首页模块管理、启动设置和配置导入导出，当前候选构建通过。
2. **草稿撤销缺少保护（已补齐）**：RELOAD 直接清空设置。现复用切页确认，取消后保留修改；控件回归通过。
3. **日志清理误删备份（已修复）**：`logs.go` 将模块目录内任意 `.old` 文件当作旧日志。新增用例复现 `settings.json.old` 被删，现仅清理已知日志；复验通过。
4. **录入中关窗可能中断快捷键恢复（已修复）**：关闭窗口前提交恢复请求，却立即退出并取消请求。现在等待 Host 确认恢复后再切页或关窗，失败保留窗口；控件回归通过。
5. **导出确认可能遗漏最终文件名（已修复，实操待验收）**：文件选择结束后才补 `.winone`，可能覆盖未经确认的同名文件。现由系统对话框先补扩展名、再确认覆盖；文件夹选择同时补齐所需初始化。

## 2026-10-05 管理员重启复审

Host 已支持识别同目录的 Rust 管理员辅助进程，但重启请求入口仍先按 `WinOne.exe` 设置窗口校验，导致 `WinOne.Host.exe` 辅助进程在绑定前被拒绝。原测试只覆盖辅助身份函数和直接调用，未覆盖二者经过真实请求入口的组合。

现按请求角色选择校验：窗口保留准备、提交和取消能力；辅助进程仅可绑定、查询及确认。新增入口回归复现拒绝，修复后通过，并验证角色权限不扩大、每次请求重查身份。实际管理员重启仍留待整套候选验收，未改动现有账户授权。
