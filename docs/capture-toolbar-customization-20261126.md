# 截图自定义工具栏单列调整

用户要求保留单列，改善当前窄长菜单的拥挤感。采用加宽的单列清单，沿用 WinOne 中性深浅色、现有 Solar 图标以及 Host 保存流程。

- 双列能减少高度，但用户明确不采用。只放大旧选中胶囊仍会让所有行同时突出，因此使用平面行和独立复选框。
- 菜单保留 13 项工具与当前顺序；每行图标、名称、复选框各占固定位置，整行可点击。
- 常规宽度约 256 DIP，行高 38 DIP，行间留白 2 DIP，左右留白 12 DIP；仅悬停行显示浅底色。恢复默认固定在底部，与工具列表分隔。
- 屏幕高度不足时只滚动工具列表，底部动作保持可见；滚轮和键盘可到达首末项。沿用当前点击保存、关闭菜单的行为。
- 不改真实安装、截图输出与工具选择规则，不增加依赖。

实施顺序：

1. 用现有私有桌面工具栏回归记录原界面，并补充高缩放下末项可达的检查。
2. 在原菜单接入单列布局、平面绘制和必要的滚动；保留社区菜单的命中、确认与关闭逻辑。
3. 检查中英文、深浅色、宽窄屏和缩放截图，验证取消、勾选保存及恢复默认；复测序号输入。
4. 更新来源摘要，提交并推送；替换固定安装器，核验载荷和 SHA-256，归档证据。

完成验证：单列布局使用 14 DIP 正文字号，宽度按完整英文名称扩展。菜单优先使用工具栏上下较大空间，列表可滚动，恢复默认保持固定。中文深浅色、英文浅色/深色、800/1280/1920 宽度及 1/1.5/2 缩放回归通过；覆盖滚轮到末项、End/Enter 恢复默认、点击外部取消、真实 Host 勾选保存与恢复。原生草稿/标注/录屏 ABI、序号输入和截图冒烟通过。

原回归将“点击 (80,80)”视为点击外部；加宽后的窄屏菜单可以包含该位置，已改用屏幕左上外边距并检查菜单确实关闭。缩放夹具同时更新真实文字资源，避免仅放大几何尺寸造成假验收。测试在私有桌面运行，不切换用户桌面。
