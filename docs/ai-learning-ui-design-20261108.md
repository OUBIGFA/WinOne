# AI 服务与英语学习界面改造

## 范围与依据

用户于 2026-11-08 要求：完成 AI 基座完整接入后，重做 AI 服务信息架构与英语学习结果页；支持持久化的忽略和加强学习。所有已有能力、保存流程、未保存保护和真实运行路径保留。本文件是实施前规划，验收结果另行补充。

资料调研不是 WinOne 用户实验。下列商业产品的功能组织用作可核查参照，不据此声称提升了完成率或学习效果。

## 用户任务与信息架构

AI 服务默认打开常用首页，回答“是否有可用服务、当前默认哪个模型、怎样添加连接”。连接与模型单独一个区域，保留自定义供应商和账号供应商两个入口。更多功能区域保留使用偏好、网关、路由、用量、插件与高级设置，入口使用具体名称和一句用途说明。错误、保存/撤销、未保存状态在当前上下文中可见。

英语学习顶部直接展示原文，默认一行，展开后查看全文；朗读在原文旁，始终读完整原文。阅读顺序为原文、重点词条、释义、可展开细节、AI 讲解。单词与词组的字号和字重高于操作文案；默认只显示释义与紧凑发音/学习状态操作。建卡、词典出处、词形与详细编辑放入详情。保留分页、全部建卡、Anki 连接检查、联网词典和错误恢复。

忽略和加强学习是每个词条独立、可撤销的持久状态。匹配采用大小写无关、统一空白和撇号的词条键；不自行猜测词根而误伤其他词。忽略词不进入句子/段落词条列表，也不因 AI 补充词表重新出现。直接查询单词仍能看到其忽略状态并恢复。加强词若出现在原文中则优先展示；生成讲解时提供匹配的重点词，且与原文数据一样不作为可信指令。

## 视觉方向

Product：在日常 Windows 工作中连接 AI 服务，并从选中文字学习英语。

Character：安静、清楚、可核对。

World：系统设置与带原文的词典阅读页。

Moments：首次连接后看见可用模型；展开原文确认上下文；重点词在下一次阅读时优先出现。

Signature：模型始终带供应商身份；学习页以大词条和紧随的释义作为主视觉。

继续使用项目原生字体、语义颜色、Lucide 图标、背景底块。按钮不靠大面积强调色争夺阅读注意力。宽窄布局改变结构和换行，不缩小正文到难以阅读。

## 审核方法与验收

使用 [Impeccable](https://github.com/pbakaus/impeccable) 4.8.1（Apache-2.0，提交 `924bbd194d02e5e15a227e75b5901fb0d7a4ecad`）的 Operate、craft-floor、critique 和 native audit 清单。上下文加载器未运行，直接读取项目设计资料。Windows MyGo 无网页 DOM，网页 detector 不适用；原生审核中 iOS/Android 特有项不计作通过。

使用 [Unslop](https://github.com/heydamir/unslop)（提交 `a6f121eee5f29c2f74976b75456feae8b66afb3a`）的九轮检查：间距、颜色、图标、文案、字体、布局、细节、视觉、动效。Unslop 由 **Damir Sokolovsky（@heydamir）** 创建，许可 **CC BY 4.0**；本文件中的五行方向和九轮审核流程依其方法适配 Windows 原生界面。

验收包括：真实生产组件的宽窄、中英、明暗截图；首屏主任务可找到；无横向滚动与裁切；键盘可达；悬停不重复；原文展开与完整朗读；忽略跨重启有效；加强词匹配与排序有效；失败不伪装成已保存；原有全部功能入口仍可到达。截图和日志位于本次隔离目录，不入库。

## 实施与审核发现

本轮按 Impeccable 的 Operate 模式检查设置页，按 Read 模式检查学习结果。Windows 使用项目原生字体、灰阶和Lucide图标；iOS/Android安全区域、网页DOM检测和触屏尺寸不计作通过。没有进行真实用户实验或读屏软件测试，不给出貌似精确的综合可用性分数。

| 发现 | 严重度与影响 | 修复与核查 |
| --- | --- | --- |
| AI首屏八个标签同时竞争 | P1，首次配置无法分辨主要操作 | 改为常用、连接与模型、更多功能；原全部页面可达测试 |
| 网关一屏混合网络、模型、密钥与身份规则 | P1，低频设置阻碍复制地址等常用任务 | 拆为连接与模型、访问密钥、网络与协议、网关会话；各自保留草稿 |
| 学习操作字号、按钮底色抢占词条 | P1，词条和释义弱于操作 | 词条22DIP/600，释义15DIP，动作降为次级文字或图标；详情与Anki单层收纳 |
| 原文朗读缺少可核对的内容 | P1，用户无法确认朗读对象 | 顶部原文一行预览、展开图标、独立朗读；测试确认始终传完整原文 |
| 320宽度恢复长按钮把词条挤成碎行 | P2，词条难以阅读 | 改为带明确辅助名称和悬停说明的恢复图标；再次渲染窄窗词条管理 |
| 学习设置分组缺内边距、字段贴边 | P2，关联和层级不清楚 | 分组内16DIP边距与间距，学习/Anki/模板分区；明暗中英560/1000复验 |
| 访问密钥没有范围候选 | P2，要求用户知道内部标识 | 从同一真实运行时读取模型、账号、MCP服务及工具；保留手填模式和未可用条目 |
| 悬停提示重复，侧栏热区占位 | P2，遮挡操作与制造白缝 | 模型提示专属归属，拖动热区覆盖边界；悬停数量和几何测试 |
| 设置请求失败后丢编辑内容、自动反复请求 | P1，无法判断是否保存 | 成功回调才清理，失败保留草稿；显式重试入口 |

Unslop九轮逐项核对：间距使用既有4DIP尺度与必要细调；表面保留中性灰阶；图标复用Lucide；文案说明动作与范围；词条、正文、次级信息三层；布局按任务和宽度组织；错误、空态、禁用、加载可辨；不添加装饰性图像；使用已有减少动效支持，不新增装饰动画。保留产品真值，不生成虚假的可用账号、使用量或学习效果。
