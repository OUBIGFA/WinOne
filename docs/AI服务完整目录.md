## 接入边界

WinOne 继续保管设置和逐供应商的私有账号目录。magpie 执行账号、插件和协议适配；不导入或切换独立客户端的账号。现有内置账号保持兼容，同一服务不因实现方式重复占据列表。

目录从锁定上游与社区元数据生成，保存包版本、来源和摘要；构建时核对覆盖，不能继续维护一份静默遗漏的手写子集。插件只在对应服务使用时加载，共享 Bun 运行时，随当前 AI Worker 退出；不启动上游设置窗口、托盘或常驻插件服务。

登录沿用现有所有者与取消协议，补齐插件的登录方式选择、前置问题、API 密钥、浏览器回调和粘贴授权码。凭据留在对应供应商的私有目录，公共配置和错误不返回明文。所有外部插件来源、版本、依赖和许可证在打包前核验，运行时使用已打包资源。

API 服务预设应复用 `provider.FromPreset` 的模型与协议能力，并保留手填地址、手填模型和多密钥；不能只填入名称，却丢掉 OpenCode 按模型选择协议或 ClinePass 的模型范围。

## 已验证的局部修复

账号页父组件与账号子组件曾同时请求智能体目录，触发 Host 的账号互斥锁。现已由父页面统一加载，子组件使用传入目录（包括初始空数组）；独立组件仍自行加载。回归先失败后通过，最终 329 项前端测试通过；实际 Rust/WebView2 + Host 页面完成账号列表、服务预设、授权输入、取消和刷新，未出现误报。

划词工具栏内层 `Border(1).Radius(12)` 与 MyGo 保留的系统外框叠加。已增加共享 `windowSurface`，用于工具栏及结果窗；窗口统一调用 `PrepareWindowFrame`，系统负责外框、圆角和裁切。OCR、翻译、划词工具栏的深浅色边缘与四角回归先失败后通过。OCR、翻译、隐藏思考以及深浅色划词完整原生流程均通过，包括复制、对话、移动/调整尺寸、窗口关闭和进程退出；工具栏验证 Windows 圆角策略为 2，并保存图像。

主设置壳没有包裹整窗的 CSS 边框；Base UI 下拉、Popover、Dialog 的单个 Popup 自身绘制边界，调用方未再包同尺寸边框；原生截图工具栏由根 UserControl 绘制一层边框，内部 ToolStrip 采用 borderless 调色板。实际设置页的根容器边框为 0、无阴影；新增预设弹窗边框为 0，仅一层 1px ring。正常控件边框、分区线和焦点环不属于重复外框。
