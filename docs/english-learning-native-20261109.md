# WinOne 内置英语学习工具

## 本次要求

2026-11-09 用户要求 Anki 全量合并进 WinOne，前端由 MyGo 重写，安装后无需另行下载 Anki 或 AnkiConnect。需要的 AnkiConnect 能力也完整接入。学习范围依据用户提供的《划词助手英语学习助手》；其中外部安装、外部复习窗口的旧设计由本次要求覆盖。保留单词、短语、句子、长文、三档水平、词典事实校准、发音、追问、逐个和批量建卡，以及既有忽略/加强学习。

本次不运行提权、联网或会干扰其他工作的交互测试。只在仓库隔离数据中执行离线检查；不改用户已安装程序、已有 Anki 集合或真实账号。三轮不同范围的审核均无未解决问题后，才能交付并替换正式安装器。未执行的联网验证明确保留为未验证，不能记作通过。

## 实现路线

复用官方 Anki 数据引擎及 FSRS，MyGo 提供 WinOne 内原生操作界面。自行重写调度器不符合要求；继续跳转外部 Anki 也不符合要求。AnkiConnect 作为生态兼容接口按实际 API 完整核对，内部调用优先走现有 Host 管理的进程通信。随包携带已锁定版本的必要运行时、资源和许可，按需启动，退出时释放。

已核对官方最新版本为 Anki 26.09.4（提交 c06370ff4d87cb48d825f90cc83e02b9a4e84ecd）；MyGo 最新正式版仍为 v0.8.3。来源：[Anki 发布](https://github.com/ankitects/anki/releases/tag/26.09.4)、[Anki 手册](https://docs.ankiweb.net/)、[Anki 扩展架构](https://addon-docs.ankiweb.net/)、Go 官方模块代理。此记录只代表来源核对，不代表完成集成。

## 实现与复核说明

Anki 与 AnkiConnect 源码保留原始字节。WinOne 适配代码位于 `modules/anki/`；集合算法、FSRS 和格式转换直接调用官方引擎。常用界面位于 `apps/desktop-mygo/studybook/`；其余完整管理字段来自上游结构描述，均有真实执行入口。Anki 卡片本身允许 HTML/CSS/脚本，因此仅卡片内容使用隔离渲染器；页面、导航、字段编辑、评分和图像遮挡编辑为 MyGo。卡片仅取得自身媒体和当前卡片调度回调，不能调用通用 Host 接口。

默认不开启 AnkiConnect 网络端口。启用后仅监听 `127.0.0.1`，要求访问密钥和明确来源。WinOne 内部使用现有已验证管道。大内容复用 `previewtransfer` 的分块、摘要验证和释放机制，不放宽所有 WinOne 消息的 1 MiB 上限。文件媒体优先按所选路径交给引擎；结果内容和批量请求需要时分块传输。

只查看学习结果时检查运行文件，不提前启动 Anki。集合首次被操作时才启动；无活动页面和编辑器时释放空闲进程。原生页面的变化检查仅在可见时运行；隐藏或关闭时停止音频、录音、自动继续及卡片页面。记录稿由实际调用进程持有，进程退出后的失效稿不阻塞下一次使用。

复核已发现并修复：新卡编辑器多传非编辑字段、列表查询未用上游关键字参数、管理表单复用旧 map 导致多余参数、默认空牌组未出现在上游到期树、操作记录被错误展开、卡片渲染缺少 bridgeCommand、编码写入造成新增中文问号、英文窄窗按钮溢出、输入值与后端整数类型不一致、大媒体超过已有管道上限。各项保留实际行为测试或渲染证据。

正式产物只有在三轮审核、包回读与安装器关联核对完成后才替换；产物摘要与来源提交以 `dist/release/release-info.json` 为准。

## 使用入口

1. 打开划词助手或快捷助手的“英语学习”。“讲解与发音”设置讲解水平、默认发音和在线词典；“学习模板”保留四类输入模板。
2. 打开“Anki 生词本”，选择学习结果的新卡牌组与背诵/默写方式。下方“牌组”用于开始复习，“浏览生词本”用于搜索、编辑和批量操作。
3. 在学习结果点击“加入生词本”，可直接保存到内置集合，不需要启动外部 Anki。点击复习或浏览入口会打开同一份内置生词本。
4. 默写卡在原生输入框中填写答案，按 Enter 显示比较结果。显示答案后使用四档评分；Space 显示答案，1–4 选择评分。复习选项、FSRS 参数和每日上限在牌组的“复习选项”中调整。
5. “学习工具”包含档案、导入导出、同步、兼容服务与完整管理操作。导入完整集合需确认替换，执行前保存备份；CSV 可先预览并调整字段。已有 Anki 数据可通过官方导出的 APKG/COLPKG 文件导入，不自动读取或迁移用户的外部集合。
6. AnkiWeb/自建同步在主动登录或点击同步后联网。需要浏览器词典连接时，启用本机 AnkiConnect，并将本页访问密钥和允许来源配置到相应工具。默认关闭兼容服务和卡片网络资源。

录音、系统语音和网络同步是用户主动触发的产品功能。本轮自动验证没有启用它们；此范围与离线集合和渲染检查分开记录。
