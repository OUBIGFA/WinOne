## 托盘统一

WinOne 已统一展示原生收纳图标与无自带图标的托管程序。受管 Worker 仅保留隐藏的消息处理窗口，不创建独立托盘图标或菜单；原生回归已验证。

2026-10-02 补验：真实屏外测试窗口已完成显示、隐藏和取消托管，恢复可见后才移除条目；窗口缺失时保留恢复入口。验证未接管用户窗口。托盘菜单的实际点击与长期使用仍需实机走查。

1. 程序管理 Worker 只负责托管、收纳、窗口操作及恢复。托管程序以稳定条目 ID、名称、图标和可用动作交给 WinOne；模块受管模式不创建自己的可见托盘图标或菜单。
2. WinOne 托盘菜单提供打开、隐藏、取消托管及退出程序等动作；原程序已有的托盘图标仍可打开原程序菜单。WebView 程序面板使用同一动作契约。
3. 禁用、退出、异常恢复继续还原窗口和图标。过期条目不能操作后来复用 PID/窗口句柄的程序；不因状态刷新启动空闲 Worker。

## 托盘失败反馈

- 操作失败或缺少送达确认时，记录到 WinOne 诊断日志，并请求一次 Windows 原生提示；点击提示打开设置。
- 提示不播放声音，尊重 Windows 的通知限制；不因后续图标更新而重复显示。完整原因保留在日志中。
- 依据：[Microsoft NOTIFYICONDATAW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ns-shellapi-notifyicondataw)，2026-10-02 核对联合字段、通知标记、UTF-16容量及点击消息。
- 原生验证：在 `third_party/systray` 显式设置 `WINONE_TEST_TRAY_REGISTRATION=1`，运行 `go test ./... -run TestHiddenTrayNotificationRegistration`。仅注册、更新和移除本测试的隐藏图标，不弹出测试通知。实际通知展示与用户点击仍属于实机走查。
