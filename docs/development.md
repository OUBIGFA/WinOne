## 已验证

- React/WebView2 设置窗口可运行，页面连接独立 Go Host。
- 主题保存落盘，深色切换可用；关闭设置后 Host 保持运行。
- 命名管道拒绝重复 Host；打包后二进制通过 30 次独立客户端连接。
- 设置修订冲突、损坏文件保护、消息长度限制、截断消息和连接取消测试通过。
- WinTray 原源码通过当前 Go 工具链构建，配置、字符串和更新检查测试通过。
- ShareX v21.0.0 截图库构建成功，测试窗口的 32×32 捕获尺寸和像素通过。
- MSVC 14.51 与 Windows SDK 10.0.26100 已安装；PowerToys AlwaysOnTop 原生项目已构建成功，带空格路径的修复补丁已保存。
- WinTray Worker 已接入 Host 命名空间，桌面概览能读取真实连接状态。
- Worker 进程测试通过：独立配置保存、测试脚本静默启动、结果文件校验、退出收尾；测试配置不修改真实系统自启。
- React 已加入程序增删、排序、启动方式、时间及频次表单；收纳图标已桥接至主托盘菜单。
- WinTray 保存事务先持久化恢复记录；进程中断、首次保存中断、记录损坏及恢复阻止测试通过。
- Capture Worker 已纳入统一构建，使用独立 .NET 10 进程，空闲且无贴图时退出。
- 截图设置、PNG 像素保真、最近截图记录、真实命名管道及正常退出测试通过。
- 实际贴图创建/关闭与编辑器取消测试通过；窗口关闭测试使用与 Host 相同的投递回调。
- 界面测试通过：保存失败保留草稿并显示恢复入口；复制失败仍显示已保存的截图。

WinTray 尚需验收：真实程序的收纳/恢复、登录调度与权限、完整旧配置迁移、模块自动退出策略和界面操作走查。

截图尚需验收：完整交互流程、真实滚动拼接、多屏/DPI/HDR、剪贴板兼容性、快捷键、退出与其他模块的协调。

## 可复现检查

基础测试与构建：`build/build.ps1`。可选截图验证需提供 ShareX v21.0.0 源码：

```powershell
dotnet build tests/capture/CaptureProbe.csproj -c Release -p:ShareXSourceDirectory=<源码绝对路径>
./tests/capture/bin/Release/net9.0-windows/CaptureProbe.exe <结果文本路径>
```

截图验证会短暂显示自身的测试窗口，不采集用户桌面内容。源码下载与结果文本放在 `_temp/<任务>/`。
