# 结果朗读

原文、译文、划词结果和每条 AI 回复的复制按钮左侧提供朗读图标。截图结果、划词助手和快捷助手直接共用 `apps/result-ui` 的实现。

- 点击扬声器开始；准备语音时显示加载图标，播放时显示停止图标。准备和播放阶段都可再次点击停止。
- 多个结果窗口共用一个播放通道。开始另一段会取消上一段；关闭窗口、新建对话或重新生成内容时停止相应窗口的朗读。宿主退出前等待取消及音频清理完成。
- 原文读取完整内容，不受两行预览限制。译文和回复去除 Markdown 标记，保留文字和代码；链接读取可见标签，Mermaid 图表不读取源码，思考过程不纳入回复朗读。
- 空内容及正在生成的内容禁用朗读。已停止或生成失败的回复可朗读现有文字。失败说明显示在对应内容下方，不覆盖 AI 请求错误。
- 使用用户选定的 Edge 在线语音，无需配置密钥。多语言音色 `en-US-AvaMultilingualNeural` 自动识别语言；本次实际验证中文与英文，其他语言未逐项试听。按钮提示说明该段文字会发送给微软。
- 长文本按 UTF-8 字节和句词边界分段，逐段合成、播放，不截断剩余内容。Windows 内置 MPEG 解码器播放 MP3，结束或取消后关闭设备并删除临时音频，不保存音频历史。

参考 [thukiwin 的 TTS 实现](https://github.com/ayzekhdawy/thukiwin/blob/8f77b5dc2abd2ec7a4b5f10c14d284f415372634/src-tauri/src/tts.rs) 与 [朗读按钮](https://github.com/ayzekhdawy/thukiwin/blob/8f77b5dc2abd2ec7a4b5f10c14d284f415372634/src/components/SpeakButton.tsx)。WinOne 使用 Go 和原生结果控件实现相同的交互与服务协议，没有引入参考项目的前端或运行时。新增直接依赖 `gorilla/websocket v1.5.3` 及其许可证已登记在 `third_party/result-ui-notices.json`；图标来自现有锁定版本的 Lucide。

## 验证入口

统一构建入口为 `build/build-results.ps1`，运行结果宿主完整测试、MyGo 选区回归及 vet 后生成候选程序。工具链从 `build/use-local-resources.ps1` 获取，输出目录使用本仓库 `_temp/<任务>/`。

`apps/result-ui/speech_test.go` 覆盖内容归属、原文完整性、320/520/1000 宽度、深浅主题、中英标签、播放状态、跨窗口取消、过期回调和宿主退出等待。`edge_speech_test.go` 使用本地 WebSocket 验证协议、长文本、XML 转义、时钟修正、取消及不完整音频拒绝。

普通测试不联网、不播放声音。显式设置 `WINONE_TEST_SPEECH_ONLINE=1` 后，`TestEdgeSpeechOnlineAndWindowsPlayback` 才向微软发送测试内固定的中英文公开样句；同时设置 `WINONE_TEST_SPEECH_PLAYBACK=1` 才通过系统音频输出播放并验证取消、临时文件清理。可设置 `WINONE_SPEECH_LAYOUT_DIR` 到本次临时目录，保存生产视图的各状态截图。

本次不更新安装器，安装器由其他任务处理。
