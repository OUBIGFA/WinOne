# 本地网关与结果划词

2026-10-08：实现用户要求的设置页调整、结果内划词、本地网关和鼠标悬停置顶。验收状态以 development.md 为准。

## 本地网关

在「AI 服务 → 本地网关」启用并保存。默认关闭，默认端口 3426，仅监听 127.0.0.1。复制 API 基础地址和访问密钥到本机第三方应用。退出 WinOne 后停止；开启状态在下次启动时恢复。端口占用时保存失败，原设置保留。

模型列表按供应商分组显示名称和品牌图标，模型使用显示名称、模型图标和勾选框。可以搜索、逐个选择、按供应商选择或批量启用/停用。候选来自 AI 服务已勾选、已保存的模型；网关选择独立保存，不改变截图、划词或对话可用的模型。

保存后，只有选中的模型进入第三方模型列表，未选中的模型即使使用原 ID 发起新请求也会被拒绝。全部取消会开放零个模型。旧配置首次使用时保留原有开放范围；修改选择后按明确列表保存，重启后恢复选择。

界面不展示内部路由 ID。第三方通过 GET /v1/models 获取调用标识「供应商 ID/模型 ID」，以区分不同供应商或账号下的同名模型。支持以下 JSON 接口：

| 接口 | 用途 |
| --- | --- |
| POST /v1/chat/completions | OpenAI Chat Completions，含流式与工具调用 |
| POST /v1/responses | OpenAI Responses |
| POST /v1/messages | Anthropic Messages |
| POST /v1/messages/count_tokens | Anthropic token 计数 |
| POST /v1/images/generations | 图像生成 |
| POST /v1/embeddings | 文本嵌入 |
| POST /v1/rerank | 重排 |

具体能力由供应商和模型决定。访问密钥支持 Authorization: Bearer 或 x-api-key。网关密钥与供应商密钥分开；磁盘只保存当前 Windows 用户可解密的密文。重置网关密钥会立即拒绝原密钥的新请求，不更改供应商密钥。当前不提供局域网监听、浏览器跨域调用或多部分文件上传接口。

协议转换直接调用锁定的 magpie c2020e0bb3060b9b69a2af65d427c6a6cb3e1a90 的 gateway.Handler。Host 保留原始 JSON 参数，复用既有密钥轮询、故障切换和独立账号目录；不再建一套供应商设置。启用后仅 Host 监听本地端口，收到请求才启动受控 AI 进程；最多 4 个网关请求，单请求最多 16 MiB、10 分钟，响应最多 64 MiB。响应开始后不换密钥重发。禁用、维护或退出会取消活动请求并回收进程。

网关配置 ai-gateway.json 属于本机配置，不进入跨设备供应商偏好。诊断不记录请求正文、账号授权或密钥。

## 结果内划词

OCR、翻译与划词结果仍使用同一结果宿主。MyGo 现有文字控件已经支持选区，但本版 Windows 无障碍实现不提供文字选区读取。构建只在隔离副本中添加一个只读 SelectedText 接口；不修改共享 Go 模块缓存，不改变文字控件、排版或剪贴板。

快速拖选还会触发上游的输入遗漏：鼠标按下与松开之间没有绘制时，末次移动未进入选区。隔离补丁在松开时提交最终坐标；无中间帧回归先失败后通过，真实结果窗的鼠标拖选与键盘选择均已通过。没有增加等待时间或改变工具栏外观。

Host 根据已登记的结果窗口、进程和一次性请求 ID 读取选中文字。工具栏本身不提供选区。自动划词、键盘划词、排除应用与模块停用规则沿用现有监听。结果和新划词工具栏之间切换焦点保留原结果；移到外部应用时关闭未固定的结果。

## 鼠标悬停置顶

置顶快捷键读取鼠标位置，通过 WindowFromPoint 和 GetAncestor(GA_ROOT) 找到当前可见的顶层窗口。无需先激活窗口；不把桌面、任务栏或无效目标替换为前台窗口。沿用已有窗口身份验证、排除名单、权限、置顶边框和状态恢复。

Microsoft 文档于 2026-10-08 核对：[WindowFromPoint](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-windowfrompoint)、[GetAncestor](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getancestor)、[SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)。适用范围为鼠标可命中的可见窗口，不是被其他窗口完全遮住的区域。
