## 性能对照

同机、同一组基准，每项三次、每次至少 200 ms，报告每次操作的中位数。旧算法用 Go overlay 加载基线文件，当前测试和编译器不变。100/1000/5000 模型用于观察增长趋势；5000 是压力样本，超过当前每供应商允许保存的 4096，不当作真实配置上限。

| 操作 | 原算法 | 本次算法 |
| --- | ---: | ---: |
| 供应商选项副本 | 7.383 μs，5340 B，44 次分配 | 1.751 μs，1872 B，14 次分配 |
| 1000 个新模型的自动规则筛选 | 4.966 ms，约 4.42 MiB | 0.205 ms，约 149 KiB |
| 1000 模型完整目录刷新 | 4.425 ms | 1.043 ms |
| 5000 个新模型的自动规则筛选 | 25.350 ms，约 22.07 MiB | 1.040 ms，约 670 KiB |
| 5000 模型完整目录刷新 | 90.329 ms | 2.680 ms |

完整目录刷新增加局部成员索引：5000 模型每次分配从约 4.74 MiB 增至 5.15 MiB。配置副本与新模型规则筛选的分配明显减少；不能把局部数据推导为整机 CPU、启动、常驻内存或所有操作的提升比例。初期测量包含其他编译负载，仅保留为排查资料，表内采用最后同负载对照。
