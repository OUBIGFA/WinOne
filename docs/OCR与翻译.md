# OCR 与翻译

状态：**2026-10-06 独立 AI服务页、多供应商和各功能模型选择已更新到日常试用版。真实账号登录由用户完成。正式版整体验收仍未完成。**

## 操作

- 工具栏常用功能最后两项为 **OCR、翻译**。
- 显式打开 OCR 或翻译结果窗后，截图画布立即结束。结果窗有六点拖动图标，识别和翻译期间仍可移动和调整尺寸，复制后继续保留。
- 原文最多显示两行并省略溢出内容；译文和 OCR 全文显示，长内容滚动。原文、译文及回复的复制图标统一放在最右侧，始终复制完整内容。
- 输入框可继续提问。“用户”消息居右，模型回复居左并保留该条回复使用的模型名称。
- OCR 快捷键默认 `Alt+Shift+A`：框选后返回桌面，在后台识别并复制，不显示识别过程或结果窗口。
- 翻译快捷键默认 `Ctrl+Shift+Q`：框选后打开独立结果窗，完成识别和翻译。
- 两个快捷键都能修改或清除；冲突按现有快捷键规则提示。
- 结果窗打开或焦点交接失败时保留截图供重试；已打开结果窗内的失败在窗口内提示。关闭结果窗会取消该窗口的未完成任务。
- 未固定时点击窗外空白处关闭结果窗；固定后保留。
- 静默 OCR 识别或复制失败时恢复原截图，显示重试提示。

## 引擎

入口为侧栏独立的 **AI服务**，位于“设置”上方。普通设置的诊断日志仍独立置于最后。

1. 在“自定义供应商”添加 API 服务；在“添加供应商”添加独立智能体账号。支持多个连接和多个账号。
2. 每个供应商只有一份模型集合。“获取模型列表”和手动填写模型 ID 共存；勾选启用，未勾选置灰。获取失败不清除手填及已有模型。
3. 在 **截图 → OCR 与翻译** 选择 OCR 引擎、翻译引擎、目标语言和各功能的供应商/模型。只有启用模型进入下拉框；凭据始终由 AI服务管理。
4. 结果窗可搜索并临时切换供应商和模型。“使用功能设置”恢复本功能选择。划词动作可以单独选择，也可跟随截图翻译或结果对话设置。

以上入口已包含在 `_temp/repository-hygiene-20261008-9513b969/archived-dist/selection-ai-20261006/`，并更新至固定试用目录。

OCR 保留 HushSnap 的 PP-OCRv6 small 离线识别选项；AI OCR 将选区发送给已选供应商，不会在失败时静默换回本地引擎。内置 Google 翻译仍可选，沿用 zencrop 的接口和智能中英互译规则。旧配置保持原来的本地 OCR 与翻译选择。

自定义 LLM 可使用 API 密钥或智能体账号。账号登录在浏览器中授权，支持设备码和手动回调；账号与模型可在设置中选择。登录保存到 WinOne 专属配置，不切换其他客户端的账号。Claude Code、Cursor 等部分智能体需要已安装官方客户端。

## 开发边界

- 现有 NativeUI 继续管理同一个截图画布；独立结果由按需启动的 mygo 原生宿主呈现，无 WebView。它显示一次后，由持有焦点的截图进程激活其已验证 HWND，再关闭画布。
- OCR 子进程通过标准输入接收 PNG，返回 UTF-8 JSON；不把截图写入临时文件，不常驻模型。
- Host 的 `ai` 服务管理翻译设置与任务。截图设置使用 `capture.ai` 同一服务别名；后续划词直接复用 `ai`。
- `ai.configuration.get/save` 管理带修订号的供应商集合、模型及任务分配。密钥按服务 ID 用 Windows DPAPI 加密，读取只返回 `hasKey`；不进入配置导出和截图草稿。旧单项设置自动呈现为可迁移配置，新格式保存后拒绝旧式覆盖写入。
- `ai.translate.start` 返回任务 ID；`ai.jobs.get` 读取结果；`ai.jobs.cancel` 取消并清除结果。任务绑定调用进程，最多同时运行四个。
- `ai.generate.start` 支持通用文本/图像及有序 `messages` 对话；`ai.recognize.start` 使用所选本地/模型 OCR；`ai.translate.start` 使用翻译任务分配。供应商、模型和密钥来自共享设置，结果窗只传已保存服务和模型的选择。作业返回请求所选模型，历史标签不随设置变化。
- 图像引用为 `{mapping, bytes}`，命名包含实际管道客户端 PID 和随机标识。Host 验证归属、长度与 PNG 尺寸后复制一次，再确认任务；最多 32 MiB、8000 万像素。不写入磁盘，不在任务轮询中反复传输图像，也不扩大普通 1 MiB RPC 帧。
- magpie API 密钥模式只接收当前请求配置的服务商；新增账号各用独立的 WinOne 用户目录，旧账号保留原目录。两者都不启动上游界面、托盘或后台刷新。
- `ai.accounts.*` 提供账号、模型、登录、取消及回调输入。每次调用受 Windows Job Object 管理；取消和结束会回收该次调用启动的客户端。
- 工具栏偏好增加 `toolbarVersion: 2`；旧自定义布局一次性补入 OCR、翻译，之后保留用户的显示选择。

## 构建

1. 使用 `build/prepare-ocr.ps1` 准备 Python 3.13.12、锁定依赖和模型；可传 `PythonExe`、`Downloader`。
