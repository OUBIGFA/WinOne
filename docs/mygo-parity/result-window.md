# 结果窗（result-ui）功能对照

更新：2026-11-01。对象：`apps/result-ui`（模块 `winone/resultui`）及其可执行程序 `cmd/winone-results`，覆盖截图 OCR、截图翻译、划词工具栏、划词结果和快捷助手五种呈现。旧实现基于 MyGo `v0.2.13-0.20261006044557-3ad015a7f887` 加构建时补丁；新实现基于 MyGo v0.7.3（与 `apps/desktop-mygo` 相同）。Host 与结果窗之间的协议（`internal/resultwindow`、`results.*` 与 `ai.*` 方法）不变。

状态：**已验证** = 有所列单元测试或实窗证据；**待验证** = 已实现，仍缺对应证据；**计划** = 初始对照清单中尚未逐项登记验收的项目。源码迁移、构建与全套回归已经通过，未更新的“计划”行不作为重新实现已有功能的理由，也不代表已通过完整实窗验收。单元测试在 `apps/result-ui/*_test.go`，`ui.Tester` 只验证组件行为，不等同于物理输入与真实供应商调用。

## 当前成果测试包

- 已随 2026-11-01 的 `dist/release/WinOne-setup.exe` 交付；这是当前 MyGo 成果预览，不是全量前端迁移完成版。
- `build/build-results.ps1` 全套测试、普通/生产 vet、原版 v0.7.3 编译、源码及二进制 12 项许可校验通过。IME Enter、无末尾换行的 Mermaid 围栏、窄窗工具栏“更多”入口等回归已纳入。
- `TestNativeResultProcess` 与 `TestNativeResultStartupProbe` 使用当前正式二进制和私有管道，通过中英 × 深浅色四组窗口：句柄/PID/令牌、置顶、工具窗口/owner、工具栏不可调整、结果窗顶边 HTTOP、空选区回执、关闭和 quit 正常退出。
- 实窗截图在 `_temp/mygo-test-installer/result-native/<主题>-<语言>/quick.png`，直接捕获正式快捷助手窗口，4 张均无黑边。内容为隔离草稿与空状态，不是实际 AI 回答验收。
- 真实 AI 账号请求、Edge 实际播放、物理中文输入法、多屏/混合 DPI、系统圆角及完整资源性能仍待验收；未读取真实配置、账号或剪贴板。完整安装矩阵与产物信息见 `docs/development.md`。
