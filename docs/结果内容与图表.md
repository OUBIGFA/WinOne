# 结果内容、图表与界面分组

2026-10-06。此实现只修改共享的 `apps/result-ui`，截图 OCR、翻译及后续划词助手使用同一组件。当前本地包为 `_temp/repository-hygiene-20261008-9513b969/archived-dist/results-ai-20261006-r5/`；正式版完整性能与兼容性验收仍未完成。

## 阅读与操作

- 原文、译文共用居中阅读列。原文预览重排 OCR 硬换行，最多两行；复制仍使用未经重排的完整原文。译文、OCR 与回答保留全部内容，可滚动阅读。
- 原文和译文置于同一浅底区域，内部用细线分隔；对话用消息图标、细线和留白区分。深色使用对应的中性底色。复制图标保持同一右边缘，重试放在其左侧。
- 仅后续对话显示思考过程，默认折叠，遵守 AI服务的全局开关。展开后固定输入区出现“收起思考过程”图标，无需回到消息顶部。
- 生成状态使用加载动效和无障碍名称。阅读区底部留白 32 DIP，输入区上方留白 12 DIP。多行输入区仍可向上拉高。
- WinOne 页面、设置标签与常用操作复用 Lucide 图标。共享按钮在窄窗允许文字换行；AI服务的供应商、账号类型及已登录账号显示对应图标。

分组依据为 [NN/G Common Region](https://www.nngroup.com/articles/common-region/) 和 [NN/G Proximity](https://www.nngroup.com/articles/gestalt-proximity/)：用共同背景说明初始结果归属，用间距区分后续对话。布局同时参考 [LobeHub DESIGN.md](https://github.com/lobehub/lobehub/blob/d0ab946b00ac4560b1682e3b8fef8ff09de0c05b/DESIGN.md) 的居中阅读区与克制元数据；没有复制该项目 UI 代码。这些依据不替代实窗验收。

## Markdown 与 Mermaid

Markdown 通过锁定的 goldmark 1.8.6 解析，由 mygo 原生控件显示标题、强调、列表、引用、表格、任务标记、代码块和链接。每条消息缓存解析结果；流式文字改变时才重建。复制回答保留原始 Markdown，代码块提供单独复制。

`mermaid` 代码围栏用于流程图和时序图。围栏完整闭合或回答结束后才启动本地渲染，显示图形并提供缩放、源码展开与复制。失败时显示错误和重试，不伪装为成功图表。

- 渲染器：`apps/diagram-renderer`，安装在 `shared/ui/WinOne.Diagrams.exe`。使用 [mermaid-rs-renderer](https://github.com/1jehuang/mermaid-rs-renderer) 提交 `3726ccbffe0e8032361eb9668694b24f77858060` 和 resvg 0.47.0，不启动浏览器或 Node。
- 文字只经标准输入传入，输出 PNG 后进程退出。中文使用本机字体；图表与字体不从 CDN 获取。Windows Job Object 在结果宿主退出时回收渲染进程。
- 源码上限 64 KiB、1500 行、256 节点、2048 边，位图约 4M 像素，超时 8 秒；并发最多一个。位图缓存上限 16 MiB，被释放图表可手动重新加载。
- HTML 不执行。链接仅允许 HTTP/HTTPS；远程图片显示为用户可打开的链接，不自动请求。SVG 外部图片解析关闭。
- 当前验收覆盖流程图、子图、时序消息、激活、注释和 alt 分支。未声明与 Mermaid 全部语法等价；不支持的内容保留源码与错误。

构建与许可通过 `build/build-diagrams.ps1`、`build/verify-diagram-notices.ps1` 接入统一构建。许可记录位于 `third_party/diagram-notices.json`。29 个供应商资产及来源哈希位于 `third_party/provider-icons.json`，设置和结果 UI 共用同一目录；浅色使用上游彩色版本，深色单色，只有黑白原图的品牌保留官方原图。

## 验证与范围

完整构建、Go/vet、前端、普通 Rust 回归与依赖许可检查通过；结果 UI 独立模块测试通过。实际窗口验证原文复制、两轮对话、供应商切换、图表渲染和源码复制、思考展开与固定入口收起、输入区拉高、处理中拖动和缩放、失焦关闭与进程退出。中英、深浅色、窄窗及 1200×700 阅读列已核对。设置页面另覆盖 520/800/1280 宽度。

本机渲染后静置约 15 秒采样：Host 与结果宿主合计私有工作集峰值 41.06 MiB、Private Bytes 峰值 134.81 MiB、平均 CPU 0.0663%，11 个采样完整；结果宿主自身私有工作集约 33.47 MiB。图表进程完成后已退出。此数据包含两轮对话与小图，不代表截图/模型生成期间峰值、冷缓存启动或长期稳定性。24 节点图渲染进程另测约 448.5 ms，工作集峰值约 17.87 MiB；工作集含共享页，不能与私有工作集直接相加。

资源采样所用流程有一次生成图片尺寸断言失败，其他行为和退出完成；随后同候选三条完整流程通过。已补充断言的实际尺寸信息，原始失败保留，不把该次流程记为全通过，也未宣称修复其间歇性原因。此前 UIA 根元素不可聚焦问题已定位为测试辅助程序行为，现聚焦实际的取消固定按钮后再验证失焦关闭。

原始记录、安装更新回执和可分享截图保存于 r5 包的 `verification/`。正式版启动预算、硬件矩阵和长期运行仍见 `docs/development.md`。
