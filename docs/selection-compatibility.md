# 划词兼容性改进（2026-11-10）

目标：浏览器、桌面软件及 WinOne 内的明确选区能及时呼出同一工具栏；保持密码保护、来源检查、取消与进程回收。

设计：保留独立读取进程与现有工具栏。先修正输入手势和 UIA 选区路径；标准文本控件与旧无障碍接口补充读取。只有明确文本手势、无可用只读接口时才允许兼容复制，保存并恢复剪贴板，禁止对密码、对象选中、失效窗口和终端发送复制。成功路径不等待无关结构事件。

参考调查（算法对照，不直接复制源码或引入依赖）：

- [selection-hook](https://github.com/0xfullex/selection-hook/tree/d8ac605db1b0a87f816f6fdfd880e054033737e5)，MIT：UIA → MSAA → 受限剪贴板；外部读取线程隔离；避免整篇文档作为选区。
- [Pot Selection](https://github.com/pot-app/Selection/tree/622e8f32c851daabe45c88481a1c59d11bc7256e)，GPL-3.0：UIA → 复制与恢复。其固定等待和只保存一种格式不直接沿用。
- WinOne 使用的 MyGo v0.8.3 输入框提供 TextPattern，可选正文未提供。旧读取程序在相同正文夹具上返回 `unsupported`；新读取程序可读出精确选区。没有升级或替换 MyGo。
- [Windows 剪贴板格式枚举](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumclipboardformats)：保留原始图片表示，由系统重新派生其他图片格式；不把旧 OLE 所有者信息作为内容恢复。

实施与验证：

- 三击保持选段链；鼠标按下按实际命中窗口记录来源；键盘按下记录组合键，先释放 Ctrl/Shift 仍能识别选区。
- 常规 UIA 读取成功后立即返回，不再先订阅整个窗口的结构事件；起点、终点与焦点命中同一控件时只走一次祖先链。浏览器首次无障碍树未就绪时仍使用有上限的结构事件等待。
- 兼容复制只用于已核对来源及密码属性的文本控件，或有文本光标的容器。终端、对象选择、失效来源不发送复制键；读取线程与输入监听分离，保留取消与短命进程回收。
- 剪贴板事务由 Host 完成，不随被取消的读取进程退出。保存文字、HTML、自定义内存格式及原始图片；兼容读取后在同一剪贴板锁内恢复。遇到不支持安全保存的句柄格式或过大内存格式时跳过兼容复制。并发用户复制由输入版本和所有者检查保护。
- 全量源码测试与 vet、完整编译、包内源码和许可证校验通过。相关 Host/selection 测试在剪贴板修复后再次通过。8,029 个打包文件回读通过。

实测范围：浏览器正文、跨链接、textarea、contenteditable、Shadow DOM、iframe、空选区、密码和错误来源；MyGo 输入框及可选正文；真实 WinOne 主窗口的 AI 服务输入框；真实全局钩子到工具栏的双击、三击、拖选和键盘选区。工具栏复制文字准确且不夺取源焦点。

读取测试中，MyGo 正文及不同剪贴板状态的成功路径为 93–102 ms；普通文本和浏览器的数十毫秒级结果沿用只读路径。完整工具栏测试包含进程启动、手势、读取与按钮可用：正文双击 383 ms、三击 312 ms，输入框拖选 365 ms、键盘选区 311 ms，真实主窗口双击 266 ms。这些是本机隔离样本，不是冷启动/P95 或所有程序的承诺，也不据此宣称通用路径比旧版快多少。

复验入口：`build/test-selection-compatibility.ps1 -OutputDirectory _temp/<任务>/<新结果目录> -ReaderDirectory _temp/<任务>/reader -AllowDesktopSwitch`。完整工具栏测试另传 `-BundleDirectory`，使用隔离 Host 与配置；`-Modes` 选择具体手势。测试桌面最多占用前台 30 秒，外层独立保存剪贴板，内部测试无论成功或失败均清理本次实例后返回真实结果。

边界：未枚举测试每个网站和第三方软件；不读取密码、不将整篇文档当选区，不尝试绕过管理员权限。终端仅走可用的只读选区接口。无可用接口、拒绝复制或剪贴板无法安全保存的控件仍可能不支持。

不新增工具栏或常驻隐藏窗口；不修改真实安装与用户配置。需要真实鼠标键盘的测试如无法在后台私有桌面完成，先说明所需交互条件。

交付检查：隔离首次安装、覆盖、两处失败回退、卸载以及配置/额外文件保留通过；Host、读取程序、正式安装器及卸载器通过安全扫描。固定安装器为 `dist/release/WinOne-setup.exe`，对应摘要与构建信息在同目录；旧包保存在本次 `_temp/selection-upgrade-20261110/prior-release/`。

最终证据：`dist/reports/selection-compatibility-20261110/`。过程失败记录也保留：早期恢复 OLE 元数据导致文字/HTML 读取为空，重放合成图片导致像素错误，已修复；一条重复测试在图片写入后由外部读取看到空快照，未将该条记为通过。图片夹具现先核对 Windows 原生位图，随后两次完整复验通过；不将此样本外推为剪贴板并发场景的穷尽证明。
