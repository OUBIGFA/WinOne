# RapidOCRLite 接入与减重

本轮采用 RapidOCRLite 5.0.0a16 官方 Windows x64 SDK，固定提交为 `d26a04c2ea2479509359391c053771b31ba8048e`。最新源码 `9c8769008c07e13867c173c786fdc66c7fb314b4` 和官方 SDK 均完成同模型对照，实际交付使用官方 SDK。该版本为上游预发布版本。

## 接入范围

| 已有能力 | 当前实现 | 验证 |
| --- | --- | --- |
| PP-OCRv6 small 检测与识别 | 两份原模型及 SHA-256 保留，字典从识别模型元数据原样提取 | 16 组图片，文字与字符坐标对照 |
| 小图 CPU 与大图 GPU | 少于 100 万像素用常驻 CPU，引擎按请求创建 Vulkan GPU 会话 | 连续大图、强制 CPU、进程内交替尺寸 |
| 单字坐标与原位翻译 | 使用上游 C API 的 `rpocr_result_words` | 贴图、截图选区真实原位渲染 |
| 短行回退 | 检测为空时以 CPU 做整行识别 | 空白后文本、短行与连续调用 |
| 阅读顺序与文字间距 | HushSnap 规则等价移植为 C# | 56 组几何、缩进、段落、竖排、URL 与混合文字样例 |
| 待命、预热与恢复 | Capture 程序的独立 OCR 模式，保留原帧协议和 Host 生命周期 | 准备、坏图片恢复、超限和截断帧、取消、进程崩溃与退出 |
| 图片输入 | 共享 .NET 图像解码，内存中转换为连续 RGB | 普通、透明、灰度、调色板 PNG 和奇数宽度 |
| 中文路径 | 原生 DLL 按绝对路径加载，模型以进程工作目录中的 ASCII 相对文件名打开 | 中文目录内的全部协议测试 |

GPU 默认的 host-visible 内存分配在本机独立显卡上遇到大图分配失败。采用上游提供的 `PPOCR_GPU_ARENA_DEVICE_LOCAL=1` 显存策略后通过。权重缓存设置为零，每个请求结束时释放会话及上游可回收缓冲。GPU 不可用时记录有界错误并使用 CPU，行为与先前入口一致。

## 实测范围与取舍

测试使用生成的文字图片，硬件为 i7-12700K 和 RTX 3080 Ti。16 组样例覆盖明暗背景、四种字号、正负 7 度旋转、竖排、空白及最高 3440×1440 图片。官方 SDK 每组运行三次，文字、文本框、单字框与旧引擎一致。接入后的独立进程再次对照 16 组文字及布局，32 项输出一致。透明与灰度等五组图片的文字及布局另有 10 项一致对照。

官方 SDK 原型的 1600×1000 样例中位耗时约 0.64 秒，旧引擎约 0.67 秒。3440×1440 样例约 1.21 秒，旧引擎约 0.93 秒。原型短单行有约 23 毫秒的退化，多行小图更快。实际接入后，另一组大小图交替样例的小图约 17–20 毫秒，旧引擎约 20–26 毫秒，大图约 0.59–1.01 秒，旧引擎约 0.63–0.92 秒。不同图片和调用路径的数值分别保留，不合并为统一加速比例。

新进程预热约 0.38 秒，CPU 样例预热后私有内存约 64 MiB，三秒空闲期间 CPU 时间增量为零。连续 15 次大小图交替后私有内存约 460 MiB，旧引擎约 513 MiB。驱动及进程堆仍会保留部分已申请内存，不能据此声称 GPU 调用后完全回到 CPU 初始占用。两边均在进程退出后释放。该测试未覆盖其他厂商显卡、真实系统休眠和干净机器安装。

## 移除范围

- OCR 打包目录移除 Python 解释器、Python 包、ONNX Runtime、DirectML、NumPy/OpenBLAS、Python OpenCV、Pillow、SymPy、Shapely 等全部旧推理链依赖。四项新运行文件合计 34,682,123 字节，约 33.08 MiB。
- 移除旧 Python 适配、依赖锁及失效的 Python 排版测试。保留可复现的图片生成与进程测试脚本，它们使用构建机 Python 和 Pillow，不进入安装包。
- 截图去掉未调用的 WPF 缩放重载及 WPF 依赖，发布只保留中英文语言资源。录屏、截图、标注、滚动截图与原位翻译照常接入。
- 原位翻译需要的 OpenCV 4.12 静态实现仍由 `WinOne.PinTranslation.dll` 提供。两份 PP-OCRv6 模型分别用于检测和识别。

源码与模型许可分别记录在 `third_party/import-notices.json`、`third_party/ocr-runtime.json` 和 `third_party/ocr-ai-notices.json`。本地对照记录和交付证据归档到 `dist/reports/rapidocrlite-20261123/`。最终安装器体积及来源写入 `docs/development.md` 和 `dist/release/release-info.json`。
