# Chat 与设置交付验收

本轮范围来自 2026-10-13 用户要求。保留工作区已有未提交更改；只在仓库内构建和使用隔离配置验证。没有修改真实安装或推送代码。

## 需求对照

| 要求 | 改动与核查入口 | 状态 |
| --- | --- | --- |
| 顶部提示、错误和侧栏标题错误可关闭 | `ChatFeedback` 保留当前关闭状态，相同轮询错误不重开；新错误或重试后仍显示 | 交互与浏览器通过 |
| 模型列表打开定位当前模型 | 打开时清理旧搜索、展开所选供应商、将所选模型滚到列表中间，焦点留在搜索框 | 单测及浏览器通过 |
| 用户消息重试 | 以所点用户消息的持久 ID 调用 Pi retry；保留原历史 | 前端请求及 Pi 集成验证 |
| AI 重命名复用 Cindy | 完整独立提示词与输出校验；显式重命名由 Host 读取保存分支；未打开旧会话不再先请求 live state | 真实 Magpie HTTP 边界与关闭会话回归通过 |
| Chat 设置保存后关闭，输入区无保存通知 | 保存成功关闭；失败保留草稿；删除输入区中的设置保存通知 | 单测及浏览器通过 |
| 新会话每次居中、只保留上方把手 | 新会话重置高度，Logo 与输入区整体居中；向上拖动时下边同步扩展；最小高度后不漂移 | 640/1120/1600 × 640/900 浏览器通过 |
| 默认对话宽度更大 | 正文与输入区采用 960px 最大内容宽度；窄窗口自动收缩 | 1600px 窗口实测通过 |
| 正文完整复用且不产生横向滚动 | 上游 `ConversationMessage`、`AIResponse`、`Markdown`；保留字体与段落规则，仅改变长代码与表格换行 | 上游样式对照 14 组、阅读间距 32 组通过 |
| 审查、文件改动和贴边问题 | 空态/错误态复用上游状态组件，真实操作使用现有 Git 后端；写入回复可打开真实审查 | 功能对照见 `chat-ui-reuse.md`；原生验证另记 |
| 更早消息过渡自然、不抢焦点 | 插入前后保留阅读位置，新增内容 200ms 淡入，尊重减少动态效果；导航令牌阻止旧历史回填 | 浏览器及跨导航回归通过 |
| 目录链接和文件链接预览 | 保留工作区内别名、句柄解析目标；外部目标只读；更换目标后旧预览 URL 失效 | junction 实跑通过；文件 symlink 创建权限不足而跳过 |
| 主侧栏保持收起 | 固定面板约束，等尺寸测量完成后恢复用户宽度；不让窄窗口比例污染宽窗口状态 | 浏览器跨断点、导航及嵌套面板通过 |
| AI 顶部占用更小 | 保留全部供应商信息；1280px、两个供应商时由 82px 降到 43px | 中英/明暗/窄宽 24 组通过 |
| 设置页顶部/底部按钮 | 共享滚动控制覆盖页面和程序管理内部面板；Chat 设置弹窗接入同一控件，无溢出隐藏 | 组件及浏览器通过 |
| 链接历史只在查找页显示 | 历史移入“查找已有链接”标签；创建页不再显示 | 链接组件与浏览器通过 |
| 最新 Magpie | 实查远端提交 `0bb0781ea065b5236a9a0014bceb84cb84324895`；保留上游 Codex zstd 请求 | 适配器、账号、许可验证通过 |
| 更新正式安装器 | 候选完整构建、原生工作台与隔离安装完成后更新固定路径及 SHA-256 | 进行中 |

## 验证入口

- `build/test-chat-interactions.mjs`：完整页面中的提示、设置、模型、欢迎布局、最小高度、960px 宽度与历史位置。
- `build/test-chat-rendering-layout.mjs`：实际组件与上游排版对照、代码复制、长内容无横向溢出、审查状态。
- `build/test-chat-ui-rebuild.mjs`、`test-chat-reading-layout.mjs`、`test-chat-experience.mjs`、`test-chat-panel-layout.mjs`、`test-chat-refinements.mjs`：正式 CSP、编辑保存、PDF、工作过程、标签与面板几何。
- `apps/desktop/frontend/tests/shell-settings-check.mjs`：主侧栏、设置滚动和链接历史的真实浏览器回归。
- `apps/desktop/frontend/tests/rust-chat-workbench-check.mjs`：隔离原生窗口、真实 Host/Pi、链接技能、文件预览、终端、暂存/取消暂存及浏览器。
