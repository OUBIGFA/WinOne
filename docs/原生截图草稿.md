# 原生截图草稿

原生文档保存图层数据，恢复后可以继续编辑。后台保存、原生会话恢复和正式启动入口已接通，测试包已更新；用户桌面体验尚待验收。

存储层已实现显式创建、更新、重读与图像加载：原图只写一次，更新只替换带修订号的元数据；恢复时在同一文件句柄上校验 SHA-256 并读取图像。读取前检查 PNG 签名与尺寸；图像文件上限 512 MiB，边长上限 65,535，像素总量上限 256,000,000。磁盘位置由受校验的草稿标识生成，不接受文档内提供的路径。

PNG 编码和文件操作由后台单写入协调器执行，等待队列只保留最新文档。不在指针移动、逐帧绘制或工具栏刷新中写盘；取消先使当前保存任务失效。保存任务结束前保留 Worker 资源。

已提交草稿的退役先写入 `retired.json`，再清理文件。读取优先检查退役标识，清理失败保留记录并返回待清理状态；重试只处理记录中的已校验标识，不能删除新草稿。退役记录本身写入失败时，不报告取消成功，也不删除原草稿。

首轮保存已拆分为登记标识、锁外编码原图、校验标识后提交。编码前取消不写图像；编码期间取消立即使草稿失效，旧编码结束后不能提交或删除新草稿。阻塞编码与新草稿同时提交的回归通过。

未提交文字与已提交图层分开保存，保留内容、位置、字号、颜色及选中范围。自动快照不确认文字、不增加撤销步骤、不结束拖动；恢复后在原位输入框继续编辑。

关闭前等待保存或退役确认；失败时保留当前画布，允许重试。已经复制的截图只重试关闭，不重复复制。原图编码失败后仍可明确放弃本次截图。

启动恢复使用编码租约排除尚在保存的进程。PNG 已完整写入、元数据尚未提交时，校验并补全提交；原图不存在时提供“重新截图”和“稍后处理”，默认保留，明确选择重新截图后才放弃旧数据。

| 数据 | 保留内容 |
| --- | --- |
| 图像与选区 | 原图尺寸、选区及原生工具状态 |
| 绘图 | 几何位置、颜色、线宽、线型、填充、阴影、圆角 |
| 箭头与画笔 | 完整点列、箭头方向、控制点、平滑和曲线参数 |
| 效果 | 区域、像素大小或模糊半径 |
| 文字 | 标识、内容、字号、颜色及实际分行位置 |

选区必须在原图内。图层可以移出画面，恢复时保持位置，由引擎裁切输出。坐标限制为 ±1,000,000，防止异常数值进入 GDI。文档最多 512 个图层、16,384 个笔画点，编码上限 768 KiB。

恢复仅初始化空白会话，不覆盖正在编辑的画布。解析拒绝未知字段、重复字段和运行时类型元数据，不保存窗口句柄、进程 ID 或引擎对象。

依赖准备仅将画笔和线条类声明扩展为 partial，使适配层读写点列；沿用上游绘制与历史逻辑。修改颜色或线宽只更新对应属性，不重置恢复后的控制点、填充或阴影。

显示布局变化时使用原生画布的缩放和平移，图层、文字和导出始终保持原图坐标。文字输入框随视图定位，缩放不更换输入控件，平移复用文字背景。

验证入口：`NativeDocumentTests`、`NativeAutosaveTests`、`NativeRecoveryTests`、`NativeViewportTests`、`ProductionCaptureProbe`。隔离测试及最终 Worker 进程验证已通过；真实 IME、多屏 DPI、用户操作和资源开销仍待验收。
