## 响应改动

- 截图确认前使用已有后台草稿写入；输出成功后，草稿退役等待放在后台。输出失败时画布与原选区保留，退出仍同步保全草稿。私有桌面注入 2000 ms 写盘延迟，复制完成从 2241.15 ms 降到 38.96 ms；同时核验剪贴板图像为 460×280。该数值说明阻塞已解除，不代表普通磁盘每次节省两秒。
- 录制按固定目标时刻推进，错过时刻直接跳到下一个，不按抖动到达时间重新开始计时，也不突发补帧。120 Hz 到达序列含 0.2 ms 抖动、目标 15 fps 的 10 秒回归，原路径仅接收 134 帧；修复后 15/30/60 fps 均保持目标数量（容差一帧）。缓冲池耗尽时不再先做显卡读回，紧密行布局直接整块复制；选区、编码、画质和有界队列不变。
- 模型列表合并与刷新筛选改为一次建立成员索引，避免对每个模型反复扫描整张列表。输出顺序、重复目录项、手动新增模型、用户取消勾选和副本隔离保持原行为。使用 100、1000、5000 模型样本；最终对照与资源数据归档至交付报告，临时索引增加分配量，不宣称内存下降。

同机成对对照保留相同新字段，仅用 Go overlay 恢复原两处列表算法。每项三次、每次至少 200 ms，以下为每操作中位数。后台系统负载未锁定，原 5000 模型刷新样本波动为 20.57–48.59 ms，不将倍数外推到整个应用。

私有桌面空配置、模块禁用的设置窗口对照：各 7 次启动，6 次重开 P95 为旧版 142.82 ms、新版 134.98 ms；没有声称启动速度显著提升。设置窗口与 Host 合计私有工作集峰值约 41.61/41.56 MiB，关窗后 Host 约 9.14/9.32 MiB。旧版打开场景只有 3 个完整样本，新版为 10 个；各次观测 CPU 平均约 0–0.01%。窗口正常退出，进程回收通过。此空配置采样不包含启用模块、真实账号或长期负载。
