# 体验重构计划

状态：实施中。以用户最新需求为准，不以现有实现限制最终体验。

## 验收原则

- 操作入口直白，结果可预期；同一能力只有一个主要设置入口。
- 不丢失未保存内容；失败保留现场，并给出可执行的下一步。
- 截图操作界面与新增模块采用成熟原生控件和 WinOne 统一风格，性能优先；置顶功能、程序管理及现有设置壳保持现状，不安排原生化迁移。
- 组件、图标、字体和样式本地打包，锁定来源、版本与许可证。图像选区及标注画布属于业务绘制，不替代组件库制作通用控件。
- 检查键盘、焦点、中英双语、主题、不同窗口尺寸和缩放；以完整用户任务验收，不以编译成功代替体验。
- “商业软件品质”作为目标，未经完整任务走查、资源测量和用户验证，不宣称已达到。

## 实施顺序

1. **未保存设置保护**：截图、置顶、启动与托盘在切页和关闭窗口前保护草稿；保存失败不丢内容，操作中不打断；保留截图编辑关闭保护。
2. **统一组件与窗口**：截图及新增原生界面复用统一组件；置顶、程序管理与现有设置壳保持现状。既有布局要求为：固定侧栏、内容区居中、可调整双栏、标签分区；统一选择、勾选、开关、数字输入及主题/语言选项。增加适合大屏的初始窗口，使用无原生标题栏的应用窗口与可访问窗口控制。
3. **重新分配入口**：首页合并模块管理；快捷键、诊断和模块偏好回到各模块；设置仅保留 WinOne 全局内容；加入 GitHub 链接（暂用明确示例地址）；托盘左键单击、双击打开设置。
4. **模块布局**：置顶面板删除窗口列表，以快捷键和偏好为主；启动与托盘重新设计程序列表，列表内提供收纳 Switch、图标状态和更换程序按钮；时间设置放常用区，参数标记“可选”并移到次要区。
5. **截图交互重构**：默认指向窗口，按住拖动改为区域；选定后四边可调整，全屏除外；标注直接在截图上展开，不打开二级标注窗口。使用同一套组件和工具栏。
6. **截图工作模式**：提供直观命名的“截完保存”和“截图后编辑”两种模式；前者保存到默认目录且不弹工具栏，后者允许标注和选择保存位置，双击执行保存并复制。检查取消、保存失败和剪贴板失败的恢复。
7. **截图工具与命名**：编辑工具默认全部显示图标和文字，“自定义工具栏”直接选择显示项并记住偏好，选项名称不带“固定”；工具栏最多两行，宽度不足时保证所有操作可访问。文字直接在截图上输入，马赛克可连续绘制，不提供独立预览步骤。默认名称 `WinOne-年月日时分秒-OK.png`，同名时才追加 `-01`、`-02`，允许自定义前缀、后缀和命名格式，禁止覆盖已有文件。
8. **完整验收**：逐项完成真实截图任务、模块设置、快捷键冲突、托盘动作、未保存保护和失败恢复；测量 Host、原生 UI 宿主、Worker 和全部辅助进程；迁移期间计入 WebView2。再滚动处理剩余安装更新、可选模块与长期稳定性。

## 整窗与内部区域的意图判断（当前方案）

2026-10-01 核对官方说明：

- [Snipaste 内置快捷键](https://docs.snipaste.com/zh-cn/key-bindings)：Tab 切换检测窗口与界面元素。
- [Greenshot 帮助](https://getgreenshot.org/help/)：交互式窗口截图先选窗口，PgDown 进入子窗口/元素选择；拖动用于自由区域截图。

案例用于参考。按用户最新要求，WinOne 采用窗口边缘与内部位置判断，不增加 Tab 切换。

当前规则：
