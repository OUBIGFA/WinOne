# 安装与进程约定

仅在任务涉及安装、更新、卸载、进程退出或需要结束 WinOne/WinTray时读取。本文件承接原项目 AGENTS.md 的约定，不改变需求。较新的明确约定优先；历史计划中的“当前顺序”须结合相关开发状态核对。

- 用户长期授权随时正常关闭或强制终止 WinOne，无需再次询问，也无需请用户代为退出。可自行选择托盘退出、已验证的关闭接口或强制终止；执行前确认目标属于 WinOne，保留已保存的配置与管理员授权。该授权只覆盖 WinOne，不覆盖其他用户程序；仍须遵守宿主权限规则。
- 用户另行长期授权正常退出独立 WinTray，无需再次询问；使用正常退出入口，保留配置。
- 采用正常退出时，可使用 computer-use 右键托盘图标并选择“退出 WinOne”；托盘操作不可用不阻塞工作，可直接强制终止已确认属于 WinOne 的进程。不以关闭设置窗口代替整个程序退出。
- 托盘退出须结束所连接的主界面和结果窗，仍保留未保存内容保护；跨安装目录连接同一 Host 也不能遗留主窗口。安装成功的完成页提供默认勾选的“立即启动 WinOne”，启动前确认维护锁已释放；取消勾选、静默安装、失败和卸载恢复不自动启动。
- 安装器和卸载器从第一页起跟随 Windows 当前用户的显示语言，不先弹出手动语言选择窗口；中文使用简体中文资源，英文及尚无翻译的语言使用英文资源。实际执行安装前重新核对安装登记，不沿用向导打开时缓存的旧版本状态。
- 只在仓库内固定维护一个正式版安装器：`dist/release/WinOne-setup.exe`。后续迭代完成必要验证后更新此文件，并同步 SHA-256；旧产物可作为证据或可恢复备份，不另设日常版本。由用户自行安装验证，不修改用户电脑的真实安装目录、真实配置或仓库外其他软件和文件；此前自动更新真实安装或日常目录的授权已撤销。自动化系统测试只能使用仓库内的隔离目录和配置。此约定不包含对外发布授权。
- 手动运行安装器必须以当前包自包含安装：首次安装、覆盖、残缺程序、登记缺失及中断操作均不要求旧包或完整旧恢复记录；旧 `.update-*` 等恢复资料保留但不得作为新安装门槛。真实配置原样保留，兼容性/缺失不阻止程序安装；启动检查用隔离配置。普通安装不自动切成卸载，不要求用户手动清理或选择修复模式。磁盘/权限/占用等真实失败必须报错并保留恢复能力，不能宣称任意系统故障下都安装成功。
- 安装器自身使用正常安装与覆盖更新流程，安装目录仅存程序，用户配置统一使用 `%LOCALAPPDATA%\WinOne`。这是用户运行安装器后的产品行为，不构成 Agent 自动安装或更新用户电脑的授权。
- 结果输入提示的机器级首次使用记录保存在 `%ProgramData%\WinOne\onboarding\result-send-hint-v1.once`。安装器以普通权限准备目录，仅给新建的 `onboarding` 目录授予普通用户继承“修改”权限；不扩大既有目录权限，不沿重解析点操作。升级、回退和普通卸载保留该记录。安装测试必须为同一初始化实现编译仓库内隔离路径，不写真实 ProgramData。
