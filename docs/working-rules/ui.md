# 界面与交互约定

## 共享组件与视觉

- 设置界面以 `apps/desktop-mygo` 为准，结果窗复用 `apps/result-ui`，共享原生能力放在 `modules/nativeui`。采用现有 MyGo 组件、Solar Linear 图标、主题与双语资源；不自绘近似控件或另造设计系统，不回退到旧 Rust/React 布局。
- 保留黑白灰方向、底色色块分区、轻边界、圆角和行内留白。设置内容使用 `kit.Panel`，带标题的组之间使用 `kit.GroupGap`；提示靠近所解释的内容。单行输入使用 `kit.TextInput`，控件选中态不加粗。
- 页面级折叠组使用 `kit.Disclosure`，标题与面板行左右各 16 DIP 对齐；内容用 `kit.Row`、`kit.Toggle`、`kit.Stack` 等行组件，避免裸字段造成第二套缩进。行内次级选项使用 `ui.Collapsible`。
- 先核对成熟开源实现，优先直接复用，再用现有组件组装或必要微调；记录来源、版本、许可和改编范围。设计参考 `open-claude-ui`、[impeccable](https://github.com/pbakaus/impeccable) 的 polish/distill/clarify/onboard 与 [unslop](https://github.com/heydamir/unslop) 的审查规则，不将参考规则描述为复制了代码或素材。
- WinOne 统一控件、令牌、图标、主题、语言、导航和错误反馈。模块按需复用宿主与运行时，不保留独立产品 UI 或各带一套常驻 UI。资源本地打包并锁定版本/许可，基础功能不依赖 CDN、在线字体或组件网站。

## 文案、分组与布局

- 页面顶部不显示重复大标题；标签已命名的唯一分组不再重复标题，只保留用途说明。`kit.Section` 的标题和说明都为空时不留白；快捷键独占标签时使用 `widgets.Shortcuts.OwnTab`。空列表说明放在分组说明位置，与标题间距 2 DIP。
- 高频操作放主页面，低频复杂设置放明确命名的二级页面；主操作使用主按钮，空闲表单不再单独显示“空闲”状态行。同类字段用途不同，用一句说明区分；文案只说明操作、可观察结果和必要限制，不暴露迁移、记录架构等内部过程，不写与实际位置相反的方位词。
- 同一可见间距只保留一个控制点，子项不叠加外边距或 padding。思考与正文间距由阅读容器统一控制，检查展开/收起、生成中/完成、段落/标题及不同宽度。
- 滚动条只按实际溢出占空间，不全局设置 `scrollbar-gutter: stable` 或固定补偿；外壳与嵌套区不重复预留，末项可达，底栏按实际内容区对齐。
- 标题、导航、动作包/场景名和列名不因窄容器无谓换行。按完整文字、图标、箭头和留白分配宽度，空间不足先调整布局，极长自定义名称才单行省略并保留完整可访问名称。覆盖中英文、图标、分栏拖宽和长名称。
- 程序列表和详情各自在区域内滚动，页面导航与工具栏不随列表滚动。程序单行排列图标、名称、托盘收纳、更换和序号下拉，不改回上下两行或上下箭头排序。空列表提示在标题下的可用区域自适应双向居中，不用固定偏移或高度。
- Tab 指示线选中与未选中时几何位置、宽度和厚度一致，只切换可见性/颜色；快速往返、嵌套、窄窗和减少动效时不越界或偏移。切换标签保留共用说明与标签组坐标，专属说明、加载和错误放在标签组下方。
- 英语学习以原文、词条、释义为主；原文默认一行，可展开并完整朗读；词条支持可恢复的忽略和加强学习。

## 导航、草稿与快捷键

- 侧栏可连续拖到 64 DIP 纯图标宽度并记忆，保留拖动把手和展开按钮；窄窗自动折叠。宽栏图标在固定槽内居中、名称左对齐；纯图标时位于栏正中，选中竖条叠加不占位。折叠前后图标尺寸、行高、坐标稳定，顶部收起按钮与导航共用中心线。
- 首页功能数量与顺序等同侧栏上半区，由 `pages/overview` 的 `TestHomeMatchesTheSidebar` 约束；增删导航同步首页映射。底部依次为互联助手、分隔线、AI 服务、设置；互联助手不列入首页。便捷功能在程序管理之后，首个标签为置顶功能。
- 所有设置页的一级、二级、嵌套标签与离开页面共用未保存确认：“继续编辑”保留原页和草稿；“放弃并离开”先还原再切换，不静默阻止或丢弃。仅切换表单取值/同一待处理项视图的标签不属于导航。
- 操作进行中的离开确认除“留在此页”外，提供“不等待，直接离开／切换／关闭”，并明确未保存更改随之放弃。页面有未保存修改时禁用模块启停，防止刷新丢草稿。
- 快捷键使用按键录入控件；录入期间保护现有绑定，退出后恢复注册并显示冲突。全局“打开 WinOne”默认 Alt+A，可修改或清空；沿用当前普通/管理员实例路由，不重复建窗，冲突时保留原绑定。
- 置顶快捷键作用于鼠标悬停的可见顶层窗口，无需先激活。主动打开 WinOne 时激活前台；程序管理关闭操作复用现有权限，确实不足时每次操作最多请求一次授权，不逐程序重复请求。
- 主题和语言只在全局设置提供入口；预览遵循正式信息架构，不把测试按钮混入公共页头。加载模块或加载失败时，全局 WinOne 日志入口仍可用；加载完成不改变当前设置标签，无日志显示空状态。
- 所有添加文件/文件夹入口支持资源管理器拖入；可批量的支持批量，路径框拖入文件夹即填写，“更换”入口拖入即替换。原生入口统一使用 `widgets.DropArea`。

## AI 服务与模型菜单

- AI 服务入口与功能范围见 [AI 服务与结果窗约定](ai-results.md)。常用页保留日常模型和结果行为，不恢复重复的“连接 AI 服务”分组；顶部供应商总数和模型预览放同一个 `kit.Panel` 紧凑行，供预览及快速定位。
- 首次配置未完成时显示连接供应商、勾选模型、选择日常模型三步引导，按钮打开现有入口，完成后自动隐藏。空供应商标签提供主操作；自定义供应商称“供应商”，“从剪贴板填写”位于连接设置首行，配额/限流暂停放在密钥下方，模型获取在列表前、为空时用主按钮。
- 供应商选择、启用、批量移除、添加、预设和设置按此顺序合并为同一栏，宽度不足时换行；操作文案使用“启用”“批量移除”“添加”“预设”“设置”。已配置供应商先显示模型，连接与密钥默认折叠。新增供应商、缺少地址或模型、账号未登录/失效时先显示必要配置。供应商设置只有一层分类，按请求、账号、额度、兼容、模型发现和服务信息归属；头像、平台额度、客户端身份和导入/导出不阻隔日常模型操作。设置分类与返回模型保留同一草稿，正在登录等操作保留离开保护。
- 预设、账号类型和批量移除弹窗共用搜索、行高与内边距；搜索固定在列表上方，提示和底部动作分行，长名称单行省略但保留完整可访问名称。批量移除明确命名后果，不将选择误写成已保存；全选范围不受搜索限制。
- 本地网关按网关运行、模型列表、连接客户端、网络与协议、访问密钥、最近调用、请求记录排列；运行状态使用徽标。模型按供应商分组显示名称、品牌/模型图标和勾选，不显示内部路由 ID；保存的选择同时约束第三方列表与调用，全部取消时不开放模型。
- 所有模型下拉共享 `modules/nativeui/modelmenu` 的搜索、供应商折叠分组、计数、图标、徽标和选中标记。设置经 `widgets/modelmenu.go` 的 `ModelMenu`/`ModelField` 供数据，结果窗经 `apps/result-ui/model_picker.go` 调用，不在页面另写列表。兼容网页菜单为 `apps/desktop/frontend/src/features/ai-model-menu.tsx`，保持同样样式；网关勾选清单不属于下拉。

## 图标、窗口与动效

- 快捷助手入口用 `Zap`（Solar `bolt` 闪电），便捷功能入口用 Solar `widget-2`。截图工具栏的模糊用 `paint-roller`，马赛克用 `checkerboard`。模块快捷键分组用 Solar 的 `SendHorizontal`，代码动作用 `CodeXml`，总结用 `ListCheck`，拖动把手用 `GripVertical`。供应商默认头像用 `Layers`，自定义供应商标签用 `LayersPlus`，添加用 `Plus`，服务动作/预设用 `PlugZap`；已识别品牌和模型使用各自图标，用户头像优先原图。预览与实际入口保持一致。
- Logo 保留完整原图、留白、比例和形状，圆形只用于外容器；缩小同时调整容器和占位，图片等比适配，不裁切或拉伸。
- Windows 装饰窗口的外框和圆角由系统负责，客户端只填背景。划词工具栏、OCR/翻译结果复用 `windowSurface` 与 `PrepareWindowFrame`；网页 Popup 只绘一层外边界，保留内部控件边框、分区线与焦点环。
- 原生菜单及子菜单共用字体、间距、边框、状态与深浅色，保留键盘、焦点、屏幕边界和高对比度支持。托盘菜单随实际内容自适应宽度，无收纳项时不留空位或分隔线；外框采用系统圆角偏好，选中行沿用控件圆角。
- 复用成熟组件的展开、收起、菜单和发送动效，尊重键盘与减少动效，不为装饰另画动画。功能性位移使用 `kit.MotionStandard`：Fluent UI `durationNormal=200ms`、`curveDecelerateMin=cubic-bezier(0.33,0,0.1,1)`；来源见 `third_party/fluent-motion/` 和 `third_party/import-notices.json`。从当前位置重定向，不弹跳、不延迟首帧、不越过过程区/输入区边界，减少动效立即就位。
- 超长思考展开后在其可视底部保留固定收起入口，不随正文滚走；共享结果页统一计时、长内容判断和折叠行为。

## 提示与反馈

- 悬停提示只用于无可见文案的纯图标按钮，侧栏仅折叠时显示。文字按钮、标签、选择框、列表、分隔线不加重复提示；保留可访问名称、必要说明和禁用原因。
- 错误使用共享原生状态反馈，兼容网页使用 Notice/InlineError；说明原因和下一步，非阻断提示用中性样式，重试等普通动作不继承错误色。
- 设置等一般提示与警告提供可键盘操作、中英可访问名称的关闭按钮；关闭只收起当前内容，不清草稿、绕过确认或解除权限限制，相同内容不逐帧重现。结果窗例外：无关闭按钮，约 5 秒自动消失，详见 [结果窗约定](ai-results.md#共享结果窗)。

## 模块设置细节

- 截图的截图后行为、文件名模板、滚动截图归为同一标签组，设置页不显示截图操作按钮或最近截图预览；快捷键独立置顶。置顶直接提供常规/高级设置，不增加“置顶设置”中间层，保留独立启停和原配置。
- 程序管理的运行次数限制、最近天数和最多次数放在“常用设置 → 时间计划”，靠近自定义时间，保留启用条件、保存字段和跨标签草稿。WinTray 功能均可在对应面板设置，不增加无用途快捷键。
- 文件/目录链接的“资源管理器集成”只显示一个开关、标题和说明，不与下一组叠加分隔线；失败或登记冲突显示真实原因。

设计依据按需查阅 [统一体验与设计依据](../统一体验与设计依据.md)、[体验重构计划](../体验重构计划.md)；视觉检查使用生产页面的 `TestShots`，通过 `WINONE_SHOTS=<目录>` 输出深浅色与宽窄布局图片。
