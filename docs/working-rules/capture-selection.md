# 截图与划词约定

仅在任务涉及截图选区、标注、工具栏、保存与划词工具栏时读取。本文件承接原项目 AGENTS.md 的约定，不改变需求。较新的明确约定优先；历史计划中的“当前顺序”须结合相关开发状态核对。

- 视频/GIF 录制开始后保留清晰的选区线框，暂停时也保留；线框和控制面板不进入成片。录制面板复用全局 Pin 图标及置顶状态表现；非置顶时点击窗外关闭，仍保护正在录制的内容。GIF 入口使用明确的 GIF 图标或三个字母，不用难以辨认的胶片图标。默认保存名在 `-OK` 前加入 `-Video` / `-GIF`；保留自定义文件名模板。
- 滚动截图按钮直接使用当前已选区域，不要求再选一次。进入长图编辑后，普通点击、右键、双击和失焦都不能隐式退出；用户通过明确的确认、保存、取消或关闭操作结束。鼠标滚轮直接以鼠标位置为中心缩放，保留原始图像像素和标注坐标。
- 视频与 GIF 录制直接使用当前截图物理像素选区，固定图标在滚动截图之后；不另开选区工具、不调用外部 ffmpeg、不落临时序列帧。用户本轮确认录制内存**不设置硬上限**，仍需有界队列、缓冲复用和按实际尺寸测量；禁止静默缩放选区或宣称未经实测的 60 MB/2 小时性能。实现与验收对照见 [录制接入](../recording-integration.md)。
- 截图界面、选区/标注与工具栏同样直接沿用用户调好的最新版 UI 源码、配置和交互，不另做原生或自绘替代界面；Rust 适配现有窗口与接口。该约定覆盖旧的截图 UI 迁移路线，既有功能引擎继续复用。
- 截图以当前 `modules/capture/NativeUI` 的现用画布与工具栏为基准，继续由既有截图模块呈现；不把历史网页编辑器替换为当前截图入口。保存和另存为成功后退出，取消或失败保留截图。
- 划词采用紧凑悬浮工具栏。Logo 容器及其横向占位一起保持小尺寸，不加外圈或独立底块；使用统一底色，Logo 与功能区用细竖线分隔，整体居中。Logo 横向区域可增加留白，圆形容器及原图尺寸比例保持；当前占位 34 DIP、圆形与原图 22 DIP。按钮 30 DIP、间距 4 DIP，使用细线图标；悬停只反馈浅底色，不增加动画或改变几何尺寸。复制默认放最后。功能可调整顺序、显示状态，并可添加自定义 AI 指令。
- 划词工具栏尾部固定提供快捷助手入口，布局为「Logo｜功能图标｜快捷助手」，两条细竖线分隔，两端占位镜像。点击后把选中文字带入快捷助手输入框，不自动发送；已有草稿时另起一段加入，并保留当前对话。
- 截图工具栏的滚动截图开关紧邻选区按钮，作为固定操作，不进入自定义标注工具的保存列表。启用后复用现有滚动采集，并在同一窗口编辑长图；取消或采集失败保留原截图。马赛克统一使用 WandSparkles 图标，绘制时不叠加“像素化 [大小]”文字。截图标注采用平面样式，箭头、形状和文字不默认加阴影；原生控件仍需统一视觉优化，不直接沿用陈旧的装饰效果。
- 截图选区与标注必须在同一窗口、同一画布中完成，选区确定后直接显示工具栏；禁止用窗口交接、隐藏重开或过渡画面替代。普通屏幕选区左键双击确认并复制，右键单击取消；长图编辑遵循本文件前述主动退出规则。不得以局部交接回归通过代替完整体验验收。当前按 `docs/截图单界面重构.md` 实施。
- 设置窗口不得兼任全屏截图窗口。截图使用独立入口和完整生命周期，完成或取消直接结束截图窗口；不得把它缩回设置页。方案经真实使用否定后先复核职责并替换不合适的实现，不用延时、临时置顶或重复显隐掩盖问题。
