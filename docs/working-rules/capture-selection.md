# 截图与划词约定

- 视频/GIF 录制开始后保留清晰的选区线框，暂停时也保留；线框和控制面板不进入成片。录制面板复用全局 Pin 图标及置顶状态表现；非置顶时点击窗外关闭，仍保护正在录制的内容。GIF 入口使用明确的 GIF 图标或三个字母，不用难以辨认的胶片图标。默认保存名在 `-OK` 前加入 `-Video` / `-GIF`；保留自定义文件名模板。
- 滚动截图按钮直接使用当前已选区域，不要求再选一次；先显示“开始”，用户点击后才滚动采集，重拍同样手动开始。进入长图编辑后，普通点击、右键、双击和失焦都不能隐式退出；用户通过明确的确认、保存、取消或关闭操作结束。鼠标滚轮直接以鼠标位置为中心缩放，保留原始图像像素和标注坐标。
- 视频与 GIF 录制直接使用当前截图物理像素选区，固定图标在滚动截图之后；不另开选区工具、不调用外部 ffmpeg、不落临时序列帧。录制内存**不设置硬上限**，仍需有界队列、缓冲复用和按实际尺寸测量；禁止静默缩放选区或宣称未经实测的 60 MB/2 小时性能。实现与验收对照见 [录制接入](../recording-integration.md)。
- 截图画布、选区、标注、长图与贴图使用 `modules/capture-native` 接入的固定 Tools3000 C++ 社区实现；OCR 保留既有算法并编译为 NativeAOT 程序。生产截图运行链不携带外部 .NET，不运行旧 C# 界面兜底。旧代码仅作兼容资料及算法来源，不迁移到 MyGo，不以仿写画布替代社区源码。
- 截图工具栏及菜单的配色、字体、图标与设置窗口统一。复用既有 Solar 图标和 `apps/desktop-mygo/kit/theme.go` 对应的中性配色；原生社区布局保留键盘、无障碍和定位行为，窄屏换行保持点击区域。适配入口在 `build/prepare-capture-native.mjs`，来源副本不直接修改。
- 保存和另存为成功后退出，取消或失败保留截图。确认、复制或取消后立即关闭截图窗口并结束任务；被丢弃草稿的原图编码与清理在后台完成，只阻止截图进程退出，不阻止下一次截图。截图进行中再按快捷键时，先激活当前截图；没有可激活的窗口时保留最后一次按键，当前操作结束后立即执行。置顶快捷键不等待截图。
- 划词采用紧凑悬浮工具栏。Logo 容器及其横向占位一起保持小尺寸，不加外圈或独立底块；使用统一底色，Logo 与功能区用细竖线分隔，整体居中。Logo 横向区域可增加留白，圆形容器及原图尺寸比例保持；当前占位 34 DIP、圆形与原图 22 DIP。按钮 30 DIP、间距 4 DIP，使用细线图标；悬停只反馈浅底色，不增加动画或改变几何尺寸。复制默认放最后。功能可调整顺序、显示状态，并可添加自定义 AI 指令。
- 划词工具栏尾部固定提供快捷助手入口，布局为「Logo｜功能图标｜快捷助手」，两条细竖线分隔，两端占位镜像。点击后把选中文字带入快捷助手输入框，不自动发送；已有草稿时另起一段加入，并保留当前对话。
- 截图工具栏的滚动截图开关紧邻选区按钮，作为固定操作，不进入自定义标注工具的保存列表。启用后复用现有滚动采集，并在同一窗口编辑长图；取消或采集失败保留原截图。马赛克使用 Solar checkerboard 图标，绘制时不叠加“像素化 [大小]”文字。截图标注采用平面样式，箭头、形状和文字不默认加阴影；原生控件仍需统一视觉优化，不直接沿用陈旧的装饰效果。
- 截图选区与标注必须在同一窗口、同一画布中完成，选区确定后直接显示工具栏；禁止用窗口交接、隐藏重开或过渡画面替代。普通屏幕选区左键双击确认并复制，右键单击取消；长图编辑遵循本文件前述主动退出规则。不得以局部交接回归通过代替完整体验验收。
- 设置窗口不得兼任全屏截图窗口。截图使用独立入口和完整生命周期，完成或取消直接结束截图窗口；不得把它缩回设置页。方案经真实使用否定后先复核职责并替换不合适的实现，不用延时、临时置顶或重复显隐掩盖问题。
- 序号标注：工具栏“序号”紧跟“文字”，快捷键 N。在选区内单击，放置下一个编号并立即显示说明底块和输入光标。编号使用圆形红底白字（默认红色，可在“样式”中调整颜色和字号），数字在圆内居中，圆形中心与说明首行垂直居中对齐；说明与输入框使用带左侧指向尖角的深灰色圆角气泡底块与白色文字，空说明显示浅灰输入提示，编辑期间不叠加第二层文字背景。输入框的宽和高随内容变化，到选区边缘时换行；说明留空时只保留编号。点击别处或按 Ctrl+Enter 确认，选区内的这次点击同时放置下一个编号；Esc 放弃本次输入并保留编号。点击已有序号重新编辑说明。用“移动”拖动序号；选中后按 Delete 删除，该删除对所有标注有效。删除、撤销和重做后其余编号自动重排。编号绘制复用社区圆形 Number badge（无阴影平面风格），说明绘制复用社区 Text handler，输入用标准 Windows EDIT，保留中文输入法组合输入。已有自定义工具栏布局在版本 3 自动加入一次“序号”，之后保留用户的选择。

“截图与贴图原位翻译”默认关闭。启用后，点击截图工具栏的“翻译”直接在当前选区显示译图；再次点击或按 Tab 对照原图。复制、保存和置顶使用当前所见图像，调整选区或修改标注后旧译图失效。关闭选项时，截图翻译沿用共享结果窗。贴图保留点击翻译、原图对照及关闭选项后取消请求并恢复原图的行为。

实现资料：[截图单界面重构](../截图单界面重构.md)、[划词助手](../划词助手.md)。

涉及 OCR、翻译结果或 AI 动作时，再读取 [AI 服务与结果窗约定](ai-results.md)。

- 视频和 GIF 分别提供默认开启的“每次询问保存地址”和默认目录；目录留空沿用截图目录。询问开启时先确认地址，取消保留截图；关闭时生成无冲突文件名。进入待录制工具栏后显示设置和开始按钮，点击开始才录制，录制中明确显示暂停/继续和结束。
- 截图不显示快捷键提示板或键帽提示。画布动作在截图助手快捷键页设置，单键仅限截图窗口，文字输入优先；窗口/控件自动框选与选区边缘吸附复用社区检测，Alt 临时绕过边缘吸附。
- 自定义工具栏使用同一画布的勾选下拉菜单，沿用 Host 保存和恢复默认；长图鸟瞰视口使用半透明填充，不能遮住底图。
