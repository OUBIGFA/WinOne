# 架构与性能约定

## 当前功能与技术边界

- main 不包含 Chat、OneBot、闪聊；完整旧版保存在 `codex/archive-full-20261112`。已移除模块的接入要求不再适用，其他功能不因此缩减。AI 服务范围见 [AI 服务与结果窗约定](ai-results.md)。
- 设置窗口使用 `apps/desktop-mygo`，结果窗使用 `apps/result-ui`，共享原生组件位于 `modules/nativeui`。截图画布与工具栏继续使用现有截图模块，不迁移到 MyGo。旧 Rust/React 桌面路线不作为当前实施要求。
- 模块提供能力，WinOne 统一设置、调用和呈现；不以独立上游应用、设置窗或编辑器代替产品接入。跨模块变更先明确配置、安装更新、双语和生命周期的共用边界。
- 修改 MyGo 前端框架前核对最新正式版（`go list -m -versions github.com/egoist/mygo`）；有新版先阅读变更并升级，同步适配、许可、构建脚本与对应模块测试。用户明确锁定版本的任务按锁定范围执行，不在同一次验证中反复刷新版本；无法升级时记录原因。

## 复用与依赖

- 指定复用的功能必须全量接入。实施前建立“上游能力 → WinOne 入口与实现 → 验证证据”对照，覆盖功能、配置、便捷操作和执行路径，不以最小实现、轻量化或已有测试范围替代完整要求。
- 适配宿主、UI、语言和配置时保留功能语义、入口及真实执行。删减、隐藏、缩小范围或以静态占位替代执行须先说明差异并取得明确授权；发现遗漏就补齐，不能省去未验证项后宣称全量完成。
- AI 基座按 Magpie 对应功能逐项接入，本地网关不承载整个上游应用，细则见 [AI 服务与结果窗约定](ai-results.md)。
- 外部代码、组件、图标、字体、模型和依赖在首次引入及每次升级时同步来源、直接/传递依赖许可与校验，不等打包再补；入口见 [即时许可检查](../repository.md#外部项目引入与即时许可检查)。专业判断先核对权威资料和成熟实现，记录来源与适用范围。

## 全量任务的持续执行与结束条件

- 已获授权的全量任务按依赖连续执行；发现缺口继续查证、修复和验证。阶段总结只报告进展，不以剩余清单、任务量大或“下一轮继续”为由停工。
- 保留已通过且未受影响的实现与证据，只复跑受改动影响的验证。提交、推送及任务要求的正式产物更新在有效范围全部完成后进行；结束前逐项核对功能对照、验证和交付文件，不以可构建或候选包代替完成。
- 只有用户要求暂停，或必须由用户提供信息、授权或外部条件才能继续时，才通过提问工具说明阻塞、已尝试措施及所需条件；同时推进独立项，不绕过权限和真实环境保护。实施状态写入 `docs/development.md`，未验证项不标为完成。

## 默认测试范围

- 默认源码检查、构建和打包不运行 HTTP 服务、TCP/UDP 监听、局域网发现、互传、登录回调或外网调用测试；本机命名管道及纯内存协议检查继续运行。产品联网功能不受此测试范围限制。
- 只有用户明确要求联网验证后才设置 `WINONE_NETWORK_TESTS=1`；账号、公开服务等专用开关仍需分别满足。FileShare 真实端口测试默认忽略。不得为通过默认检查开启联网测试、放行防火墙或重试授权弹窗。
- 系统交互测试须显式选择，界面测试使用仓库内隔离配置与私有桌面，不抢用户前台或操作真实应用。联网测试不扩大为注册账号、付费、对外发布、向他人发消息或修改系统网络设置的授权。

## Windows 本地验收与发布策略

- Windows 版本、桌面与托盘、UAC/登录/Explorer、输入法、多屏/DPI/HDR、锁屏/睡眠/远程桌面、干净机器、安装生命周期及 Defender 均保留为本地测试能力，按任务影响范围选用，遵守上述隔离与显式开关。
- 提交、推送、固定安装器更新和发布不以 Windows 验收矩阵或通过报告为前置条件，也不要求 SmartScreen 信誉、Windows 代码签名或微软样本复核。历史文档中的相关发布门槛不再适用，场景、复现步骤和缺陷记录仍可用于回归。
- 交付按实际改动核对源码测试、编译、静态检查、来源许可、版本、包清单、产物对应关系及 SHA-256，见 [交付检查范围](../repository.md#交付检查范围)。本地测试如实报告成功、失败、跳过和未覆盖，不把失败改记为通过；发现的产品缺陷按实际影响处理，平台支持和配置保护要求不变。

## 性能与生命周期

- 性能优先：选型前定义预算并测量同负载原型。相关改动按影响范围统计 Host、UI、Worker 和运行时辅助进程的冷/热启动、响应、CPU、内存、句柄、包体及退出回收；保留网页时计入 WebView2，不只测主进程。
- Host 私有工作集约 43 MiB 可接受，少量波动结合稳定性、持续增长、CPU 和回收判断，不沿用旧 40 MiB 硬门槛。启动 300 ms 保留为优化目标，交付取舍按当前任务的明确要求执行；测量结果如实记录，不以预热、隐藏常驻、减少功能或放宽指标掩盖成本。
- 禁用模块不常驻、不轮询；新模块提供资源增量和退出回收证据。已被实际体验否定的方案先查根因，必要时替换流程，不叠加延时、过渡画面或硬编码补偿。
- MyGo 设置窗口关闭后释放窗口与 UI 进程；`keepUIRunning` 仅为配置兼容保留，不提供设置入口，也不决定窗口生命周期。保护未保存内容和运行中任务，批准关闭后先隐藏，再保存位置并释放页面和进程。
- Host 与已启用模块按各自任务条件运行，关闭设置窗口不等于退出 WinOne。托盘退出、权限重启及 Host 正常退出均应回收界面进程。

测量方法与历史数据按需查阅 [性能基线](../performance-baseline.md)，不把历史实施顺序当作当前约定。
