# 模块与配置约定

仅在任务涉及模块生命周期、程序管理、配置迁移和共享依赖时读取。本文件承接原项目 AGENTS.md 的约定，不改变需求。较新的明确约定优先；历史计划中的“当前顺序”须结合相关开发状态核对。

- 模块不保留独立的产品设置、托盘入口或管理界面。WinOne 接管全局配置与 UI；程序管理模块的收纳图标和无自带托盘图标的托管程序，统一通过 WinOne 托盘菜单呈现与操作。兼容旧 WinTray 配置，不单独展示“导入 WinTray 配置”入口。
- 截图、划词助手、快捷助手、置顶、WinTray、鼠标手势是默认基础模块，均可单独启用或禁用；新增模块按统一契约支持按需下载、本地加载与卸载。禁用必须释放快捷键及后台资源，妥善恢复窗口、托盘与系统状态。
- 跨设备配置必须区分可迁移偏好与本机绑定；导入需预览、校验、处理缺失路径/模块与冲突，不迁移 HWND、PID、凭据或系统恢复账本。
- 默认页、保持界面后台运行和“打开 WinOne”快捷键属于可迁移的全局偏好；旧档案未含相应字段时保留本机值。管理员授权不导出，导入也不重置；快捷键冲突按选中的导入内容与本机保留内容共同检查。鼠标手势动作脚本保留原文并完整预览，程序和 DLL 路径通过本机映射指定。

实现资料按需选择：[模块与配置契约](../模块与配置契约.md)、[共享依赖设计](../共享依赖设计.md)、[WinTray功能接入对照](../WinTray功能接入对照.md)。不要递归展开全部链接。
