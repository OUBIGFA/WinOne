# 助手默认提示词

2026-10-08 更新。划词助手与快捷助手共用默认功能，复制功能保持原行为。

默认指令借鉴 ASD-STE100 的受控表达原则：短句、主动句、一个句子表达一个主要动作、同一概念使用固定术语，保留条件与不确定性。此处是写作方法，不宣称取得标准合规认证。请求提示词不写第三方客户端、网关或调用链名称。

| 功能 | 输出要求 |
| --- | --- |
| 翻译 | 完整保留含义、语气、段落、必要换行、标题、列表、表格、代码块和链接；仅返回译文 |
| 解释 | 先说明主要含义，再解释必要术语；区分事实、推测和无法确定的内容 |
| 总结 | 先写主旨，保留影响结论的事实、数字、单位、条件和例外；不补充无依据的结论 |
| 润色 | 使用常用词、主动句和短句；保留含义、语气、事实、原语言和排版，仅返回改写后的正文 |
| 代码 | 说明具体问题与依据，给出必要的最小修正和检查方法；没有运行证据时不声称已测试 |

默认指令实现在 internal/resultwindow/actions.go；共享翻译指令位于 internal/ai/translation_prompt.go。仅将内容完全匹配旧版默认值的提示词更新为新版。保留用户修改过的提示词、名称、顺序、显示状态和模型选择。自定义功能继续将指令与待处理内容分开传递。

截图翻译和划词翻译都可从结果区的模型名称下拉切换模型。默认自动重译，可在「AI 服务 → 默认 AI 服务」关闭。关闭后选择模型只改变下一次翻译所用的模型，点击结果区重试才开始。翻译不会改变对话区单独选择的模型。

结果呈现保留换行、段落及 Markdown 结构。截图首先依赖 OCR 的识别结构；实际翻译完整性仍取决于模型返回内容，不能恢复 OCR 已丢失的字体、坐标或结构。
