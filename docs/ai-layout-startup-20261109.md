# AI 服务整改与管理员窗口启动

范围：固定 Magpie `c9d253e4a2e7add1e31578244eda52bfdce11258`、社区插件 `d54df279c0ce9ca35a79e72cb2d81ba368b37358`、MyGo `v0.8.3`。本次不升级依赖，不修改真实安装、用户配置或管理员任务。

## 页面与移除范围

- AI 服务使用普通设置页的 `kit.Page`、`kit.PageWidth` 和外层滚动区；标题、导航、正文同宽。删除 AI 独立全宽滚动入口。
- 一级导航固定为常用、自定义供应商、账号供应商、使用偏好、更多功能。网关、路由、用量、隐私、插件和高级设置归入更多功能。
- 移除资料库和外部客户端会话的页面路由及内置插件开关。保留已有数据和插件工具所需的共享服务；Chat、WinOne 调用记录、用量中的会话统计不属于删除范围。
- 路由组、请求记录、账号与密钥池均有明确入口。组编辑独立显示，基本信息、成员、规则、高级策略和账号共用一份草稿。窄窗口标签换行。

## 管理员启动原因

安装完成会启动普通入口，已保存管理员偏好时通过授权任务转交。任务调度接受不表示进程或窗口已经准备好。原 `activateRedirected` 只等 8 秒，且消息窗口存在就算成功；真实主窗口在稍后才附加和显示。

只读现场记录中，管理员任务开始与 Host 启动相隔约 7.3 秒，接近旧上限。这个记录支持冷启动竞态判断，不能证明用户当次每个阶段的精确耗时。

修复共用 60 秒的有界就绪期限，保留路径、进程和用户身份校验；只有真实目标窗口可见才返回成功，就绪立即返回。私有桌面回归分别延迟 9 秒建窗、附加后再延迟 750 毫秒显示。旧版两例失败，修复版通过；关闭、草稿、托盘和慢清理回归继续通过。

## 局域网二维码、程序保存与结果提示

- 文件互传的局域网二维码原先直接使用 worker 的独立 `qr` 字段，复制链接使用 `url` 字段。两者不一致时扫码会走旧地址。当前候选 worker 的 SVG 和原生渲染均能解出 key，未复现用户当次安装中的原始字段；本次在页面直接复用已有 go-qrcode 生成器，以当前选中网卡的完整链接生成二维码，与复制动作共用同一字符串。缓存随地址（含 key）变化刷新。
- 新增实际二维码解码验证，覆盖过期图片仍配新链接、原生页面渲染、手机 320/390/768 像素、只读与可上传分享、原文件下载、手机文件选择上传及完整内容回读、只读上传拒绝、凭据换 Cookie、中继不可用及停止提示。`build/test-interconnect-phone.mjs` 接受 `WINONE_QR_RENDER_TEST_EXE`，使用 `build/browser-tools` 锁定的 jsqr 1.4.0；依赖仅供验证，不进入产品。
- 程序管理此前每次设置变化均执行完整任务同步、托盘路径应用和窗口语言更新。现在已成功初始化的管理配置只同步变化涉及的任务与托盘状态。窗口行为、启动间隔、退出时限等变化不再重新扫描计划任务或挂接未变的托盘。首次启动、失败恢复和回滚仍完整执行；真实自启变更仍等待成功回执。
- 私有桌面中使用正式 Go 1.26.2 工具链的真实 WinTray worker，连续 5 次修改与回读耗时 55.3–78.0 毫秒（测试轮询间隔 50 毫秒）；这不是用户真实系统自启变更的耗时。单元回归检查所有计划任务输入、未变字段及失败后的完整还原；真实进程确认保存不启动被管理程序。
- 结果页顶部、错误、朗读、输入和学习提示均去掉关闭按钮，使用同一 UI 时钟在 5 秒后隐藏；重复复制重新计时。错误和草稿本身保留，窗口关闭按钮保留。中英、明暗、窄窗、重复操作及不影响进行中请求的回归通过。
