# 安装与覆盖更新

开发包和正式版使用同一正常安装流程，不区分用户配置或设置“测试版不支持升级”的限制。默认程序目录为 `%LOCALAPPDATA%\Programs\WinOne`，配置、账号与偏好统一位于 `%LOCALAPPDATA%\WinOne`。程序目录可改，配置目录不随安装包版本变化；自动化测试通过显式参数使用隔离配置。

安装器和卸载器先通过 `GetUserDefaultUILanguage` 读取 Windows 当前用户的显示语言，再显示第一页或错误提示。中文使用简体中文资源，英文及尚无翻译的语言使用英文资源；不先弹出手动语言选择窗口，不沿用上次安装语言覆盖当前系统显示语言。

安装器检测到现有安装登记后，调用 `build/installer-update`。它复用 `internal/distribution` 的清单校验、维护锁、备份、逐文件事务、启动检查与回滚。允许更新到较高版本，也允许手动安装相同版本；自动更新的版本比较仍只选择较高版本，较低版本不会覆盖当前安装。

向导打开时读取的安装目录只用于预填。执行前必须重新读取当前安装登记，避免旧版在向导打开期间完成卸载后，仍把已删除的目录交给覆盖更新程序。目录和登记若在执行中再变化，后续维护锁与文件校验继续拒绝不一致状态。

旧安装不需要保留原 ZIP。维护程序从已经校验的清单文件重建包，仅处理清单内程序文件；配置和其他文件保留。安装目录的上级路径若是 Windows 目录链接，先解析真实路径，再在真实目录旁创建 `.update` 恢复目录。恢复目录保存旧程序、安装登记、快捷方式、卸载程序和事务记录。后续成功安装保留已有恢复目录；同一个安装包可以继续中断的文件事务。

卸载时，管理员授权任务若通过完整结构校验但属于另一个 WinOne 安装目录，则予以保留。它与损坏、被修改的任务分开处理。正常启动仍严格校验当前安装入口，不能借另一目录的任务执行任意提权命令。

本地验收必须执行安装器本身：安装旧包 → 安装同版本新包 → 再次安装相同包 → 卸载，并另测启动失败回滚后卸载。底层 `ExecuteUpgrade` 测试通过不能代替该入口流程。还需验证准备失败可重试、中断可继续、未知文件保留、配置不变，以及完成页的启动选项。

依据与范围：沿用 [NSIS 安装器命令行约定](https://nsis.sourceforge.io/Docs/Chapter3.html#installerusage) 和现有 Wails/NSIS 构建路线；程序数据使用 Windows 当前用户的 Local App Data。清单摘要用于完整性验证，不作为发行者签名。
