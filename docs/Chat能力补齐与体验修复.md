# Chat 能力补齐与体验修复

本轮按 2026-10-10 用户要求实施，保留工作区已有改动。验证使用仓库隔离目录；本地集成与安装矩阵已通过，固定安装器与摘要已更新。勾选表示实现及相应本地回归通过，不代表真实账号或全部硬件场景已覆盖，详见 [本轮验收](2026-10-10-Chat补齐验收.md)。

## 设计与复用边界

Chat 保留现有 Go Host、Pi 会话运行时和 React/Base UI 组件。继续直接复用已登记的 Cindy 输入与对话组件、LobeHub 模型资源，左右分区使用现有 react-resizable-panels。Codex 用于信息架构与能力对照，不将其未公开的桌面 UI 说成源码复用。

Pi 1.1.0 已提供 AGENTS.md、技能、扩展、MCP、历史分支、压缩和工具权限管线。本轮接通这些已有能力，WinOne 只负责设置、会话索引、界面与任务调度。MCP 工具和插件工具经过同一权限审核。插件支持本地目录；Codex 插件清单中的技能与 MCP 使用对应公开格式。

默认工作目录设置只影响新对话。删除对话回收其专属历史与草稿，不删除工作文件。自动化由 WinOne Host 调度，关闭 WinOne 时不运行；不安装系统计划任务，不补跑关机期间的每一个错过周期。

## 实现位置与检查方法

会话设置、目录和任务状态由 `internal/chat` 管理，RPC 在 `apps/host/chat_windows.go`；Pi 适配在 `modules/chat-pi`，使用其 SDK 的资源加载与 MCP 扩展。前端集中在 `features/chat*`，现代对话框在 Rust `dialogs.rs`。行为测试与实现同目录；跨进程和可视检查使用 `build/` 入口。各工作线使用独立文件范围并由当前 Agent 进行集成。
