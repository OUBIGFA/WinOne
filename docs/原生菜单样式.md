# 原生菜单样式

WinOne 的截图菜单、截图置顶菜单及 Host 托盘菜单共用以下规则：

- 字体：Segoe UI，10 pt。
- 浅色：白色背景、深色文字、中性灰选中状态。
- 深色：`#171717` 背景、`#FAFAFA` 文字、`#262626` 选中状态。
- 行高、内边距及图标随 DPI 缩放；操作、勾选状态和子菜单箭头保持清晰。
- 高对比度使用 Windows 系统菜单配色和渲染。
- 菜单打开后保持内容与主题稳定，关闭后释放菜单、字体、画刷和图标副本。

截图菜单复用 `NativeMenuTheme`；托盘菜单保留 Win32 HMENU、原生命令和焦点处理，以 owner-draw 绘制菜单项。菜单文字通过 MSAAMENUINFO 提供给辅助技术，不向 Windows 保存 Go 对象指针。

依据：

- [Microsoft：Owner-drawn menu items](https://learn.microsoft.com/windows/win32/menurc/using-menus#creating-owner-drawn-menu-items)
- [Microsoft：MSAAMENUINFO](https://learn.microsoft.com/windows/win32/api/oleacc/ns-oleacc-msaamenuinfo)
- [Microsoft：WM_MENUCHAR](https://learn.microsoft.com/windows/win32/menurc/wm-menuchar)

已验证的范围和未完成验收见 `development.md`；源码或隔离渲染通过不等于用户桌面验收通过。
